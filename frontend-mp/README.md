## 退役决策

- 依据：`docs/2026-09-17-UX体验架构设计.md` §2 端战略（frontend-mp = 退役）。
- 原因：三端（frontend / frontend-admin / frontend-mp）并行维护成本高于收益；
  用户端核心旅程（问答 → 报告）在响应式 Web 上即可完成，小程序无独占能力依赖。
- 沉淀：小程序会话页经验（`src/pages/chat/`）在移动断点适配时作参考，**代码不迁移**。

## 约定

1. 本目录**不再新增功能、不再修非阻断 bug**；依赖升级也不再投入。
2. 后端 API 变更不承诺本端兼容；接口下线时本端不做适配。
3. 如未来重启移动端，优先评估 Flutter/RN 或继续响应式深化，而非复活本端。
