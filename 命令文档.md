# 项目命令精简版

## 启动 / 停止

后端 `8000`，前端 `3000`

| 操作     | 命令                |
| :------- | :------------------ |
| 启动全部 | `.\start_all.bat`   |
| 停止全部 | `.\stop_all.bat`    |
| 重启全部 | `.\restart_all.bat` |

访问：前端 `http://localhost:3000`，API 文档 `http://localhost:8000/docs`

### 手动启动

powershell

```
# 后端
.\.venv\Scripts\python.exe -m uvicorn app.server:app --app-dir backend --host 127.0.0.1 --port 8000 --reload

# 前端开发
cd frontend
.\start_dev.bat
# 或
npx next dev -p 3000

# 前端生产
npx next build
npx next start -p 3000
```



### 常见问题

- 端口占用：`.\stop_all.bat`，或 `netstat -ano | findstr :8000` 后 `taskkill /F /PID <pid> /T`
- 缺 venv：确认 `.venv\Scripts\python.exe`
- 接口不通：确认后端已启动，`/api/*` 转发到 `API_URL`，默认 `http://localhost:8000`
- Docker：`docker compose up -d`

## 评测 CLI

bash

```
python -m backend.evaluation              # 全量：planner + rag + sql + e2e
python -m backend.evaluation rag          # 仅 RAG
python -m backend.evaluation planner      # 仅 Planner
python -m backend.evaluation sql          # 仅 SQL
python -m backend.evaluation e2e          # 仅 Graph E2E
```



Windows 可用：

powershell

```
.\.venv\Scripts\python.exe -m backend.evaluation ...
```



### 模块行为

| 模块      | 离线默认                   | `--live`                         |
| :-------- | :------------------------- | :------------------------------- |
| `planner` | 跳过                       | 真实 LLM 评分 DAG                |
| `rag`     | 检索指标 Recall/MRR/语义   | 生成层 / RAGAS / Judge           |
| `sql`     | gold SQL 安全校验 + 健全性 | 真实执行 SQL，比对结果集         |
| `e2e`     | 健全性 + Guard 规则拦截    | 真实执行整图，含 workflow 副作用 |

⚠️ `e2e --live` 可能发邮件等，请在测试环境运行。

### 常用参数

| 参数                                    | 说明                                         |
| :-------------------------------------- | :------------------------------------------- |
| `--smoke`                               | 每模块 5 条，冒烟测试                        |
| `--verbose`                             | 逐条输出状态、得分、错误                     |
| `--live`                                | 真实 LLM 调用                                |
| `--judge`                               | LLM-as-Judge，隐含 `--live`                  |
| `--selection ci_golden`                 | 从 `datasets/rag/ci_golden.jsonl` 加载选择集 |
| `--dataset custom.json`                 | 自定义评测集，用 rag runner 跑               |
| `--tier all/smoke/core/hard/regression` | 按 tier 过滤                                 |
| `--no-ragas`                            | 跳过 RAGAS，只用自研语义指标                 |
| `--ragas`                               | 跳过自研 semantic，只用 RAGAS                |
| `--ragas-level basic/standard/full`     | RAGAS 档位，默认 standard                    |
| `--semantic-thresholds '{...}'`         | 自定义语义阈值                               |
| `--regression`                          | 与上次 baseline 对比                         |
| `--promote-baseline`                    | 提升本次为 baseline                          |
| `--compare latest`                      | 与最近历史跑分对比                           |
| `--output DIR`                          | 报告输出目录                                 |
| `--runner-config MODULE`                | 自定义 runner 注册模块                       |

### 示例

bash

```
python -m backend.evaluation rag --smoke --verbose
python -m backend.evaluation rag --no-ragas
python -m backend.evaluation rag --selection ci_golden --regression
python -m backend.evaluation rag --live --judge --promote-baseline
python -m backend.evaluation e2e --verbose
python -m backend.evaluation e2e --live --verbose
python -m backend.evaluation e2e --tier smoke --live
```



## SQL / E2E 速查

powershell

```
# SQL 离线
.\.venv\Scripts\python.exe -m backend.evaluation sql

# SQL 真实执行
.\.venv\Scripts\python.exe -m backend.evaluation sql --live --verbose

# SQL 冒烟
.\.venv\Scripts\python.exe -m backend.evaluation sql --smoke --verbose

# SQL tier
.\.venv\Scripts\python.exe -m backend.evaluation sql --tier core

# E2E 离线规则校验
.\.venv\Scripts\python.exe -m backend.evaluation e2e --verbose

# E2E 真实执行整图，注意副作用
.\.venv\Scripts\python.exe -m backend.evaluation e2e --live --verbose

# E2E 冒烟
.\.venv\Scripts\python.exe -m backend.evaluation e2e --smoke --live

# E2E 回归对比
.\.venv\Scripts\python.exe -m backend.evaluation e2e --compare latest

# E2E 提升 baseline
.\.venv\Scripts\python.exe -m backend.evaluation e2e --promote-baseline
```
