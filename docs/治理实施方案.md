# P6.3 加入 must_change_password

本轮直接实现，不留“永久临时密码”的中间状态。

用户表新增：

```python
must_change_password: bool
```

默认：

```text
false
```

管理员：

```text
创建用户
或
reset password
```

以后：

```text
生成随机临时密码
must_change_password=true
revoke_user_sessions()
```

用户使用临时密码登录后：

```text
JWT / current user context 能识别 must_change_password=true
```

此状态只允许：

```text
change password
logout
必要的 current-user/profile
```

其余业务 API 返回统一错误，要求先修改密码。

成功修改密码以后：

```text
must_change_password=false
```

然后重新签发/刷新正常 token。

不要允许临时密码长期使用。
