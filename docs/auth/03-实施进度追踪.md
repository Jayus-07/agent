**冒烟结果：9/9 全绿**（login/refresh 轮换/错误密码拒绝/info+网关头组/登出/黑名单写入）。口径说明：登出后 401 拦截属网关职责，P2 接入后验证；P1 验证吊销数据层（Redis auth:blacklist: 写入实证）。

**P1 期间修复的 4 个旧系统存量缺陷（全部冒烟实证后修复）**：
1. SecurityConfig 未放行 /auth/refresh → 刷新永远 401（旧前端从未实现刷新调用，24h TTL 掩盖了它）。注意 context-path 下 antMatchers 匹配 servletPath，必须带裸 `/refresh`。
2. PermissionCache.getUserDeptId 缓存未命中 NPE → info 500（切面 DB 回退永远走不到）。
3. Spring Security 内置 LogoutFilter 劫持 POST /auth/logout（302 跳登录页）→ 自定义吊销逻辑是从未生效的死代码。已 `.logout().disable()`。
4. JWT TTL 注释误导 + 黑名单前缀不一致（P0 已修，P1 实证 auth:blacklist: 前缀生效）。

**部署链工程教训（后续复用）**：Git Bash 调 docker 需 MSYS_NO_PATHCONV / cygpath -w；nacos:2.2.3 镜像启动脚本忽略 JAVA_OPT_EXT，修 cgroup v2 崩溃要用 JAVA_TOOL_OPTIONS；**Windows bind mount 上 Maven 增量编译不可靠，deploy.sh 必须 clean package**；deploy.sh 全程幂等可重跑（M1/M2 有 information_schema 守卫）。

**P2 必须知道的事实**：
- JWT 实测为 **HS512**（JJWT 按密钥长度自动选），header `{"alg":"HS512"}`；claims：userId/username/type/deviceId + jti=userId 字符串 + sub=username + **iss=MyApp**（代码默认值，nacos yaml 未配 jwt.issuer——P2 网关验签 issuer 必须同为 MyApp，或统一在 yaml 加 jwt.issuer 并双端一致）。
- access TTL 实测 2h 窗口生效（ARCH-14）；refresh 7d；refresh_token Cookie 带 **Secure 标志**——纯 http:// 环境浏览器不会回传该 Cookie。**P2 前端接入需 https 或把 Secure 改为可配置**（建议加配置项 jwt.refresh-cookie-secure，本地开发关闭）。
- auth-service CORS 白名单为 localhost:3000/8800（SecurityConfig）——P2 走网关后跨域由网关统一处理，该配置保持不动。
