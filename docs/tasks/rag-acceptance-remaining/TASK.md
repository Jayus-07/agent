# RAG 验收剩余项

## 目标

完成 RAG 生产验收清单中仍开放的门禁，使用可复核证据更新验收结论。不得把局部测试通过或单次探针结果表述为生产就绪。

## 范围

- 关闭上传/索引观测指标等仍为部分完成的项目。
- 对已修复的延迟问题完成要求的干净观察窗口，并复核 Trace 与 SLA 数据。
- 按原计划记录证据、风险和退出条件；不能通过降低阈值或改写历史证据来关闭门禁。

## 验收标准

- 各开放清单项有真实执行证据，或有明确的未实测原因和责任边界。
- 延迟观察窗口满足清单要求，历史超时与新观察数据分开报告。
- 只有所有正式门禁满足时才允许声明 `RAG_PRODUCTION_READY=true`。
