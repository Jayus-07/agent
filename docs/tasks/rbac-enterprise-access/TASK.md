# RBAC 企业化用户、客服与部门主管

## 目标

将平台用户管理、客服团队管理和部门主管范围授权拆开，并由后端强制租户及部门边界。

## 范围

- 用户页只管理平台角色、部门、账号状态和基础资料。
- 增加客服团队页；客服档案只允许绑定到标记为客服部门的本租户启用用户。
- 用户调离客服部门时，在同一事务停用客服档案并停止接单。
- 部门主数据支持标记客服部门、设置一名部门主管并写入审计。
- 部门主管只可查看和维护自己负责部门的成员资料、账号状态，不能配置平台角色、调部门、管理客服档案或执行全局账号操作。
- 更新授权规范及本地迁移登记。

## 验收与停止条件

- 后端管理接口以可信 JWT 用户、租户及数据库部门关联做授权；不依赖前端显隐。
- 管理端展示与上述权限边界一致，部门主管可从导航进入本部门用户管理。
- Python 语法检查、前端构建和本地独立运行验证完成后提交任务分支。
- 不推送 GitHub，不合并 main；完成后等待用户验收及合并/重建确认。
