# RAG 解析与内容单元治理

## 目标

修复混合 PDF 的页面级 OCR 覆盖、复杂页面阅读顺序、原文到 AST 内容对账、结构质量分数虚高和混合结构文档的全局主策略偏置。

## 范围

- PDF 按页区分空白页、原生文本页、OCR 目标页和最终未解析内容页。
- 普通 PDF 保留快速解析；检测到常见双栏时启用本地 bbox 几何阅读顺序回退。
- 增加 PDF 原生文字层到 AST 的逐页独立对账，并明确 OCR 页面未被该审计验证。
- 将结构置信度、内容覆盖率和语义质量拆开记录；旧 `completeness` 仅作为结构置信度兼容字段。
- 多个根级内容单元类型不同时，按章节局部分派 QA、Legal、Step、Table 或 Structure 策略。
- 同步 RAG 现行文档；不接入云端解析服务，不执行数据库索引发布。

## 验收

- 实际解析矢量扫描页、空白页、双栏页和员工制度 PDF。
- 实际运行混合 FAQ/条款 AST，确认局部策略计划和输出 Leaf。
- 运行语法检查、`git diff --check`，审阅新增差异和未覆盖边界。
- 不提交；向用户展示差异与验证证据后等待提交确认。
