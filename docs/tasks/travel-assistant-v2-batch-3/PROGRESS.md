## 实施证据

前一轮歧义期间的短暂草稿已回退，未部署。本轮已新增结构化操作端点和 V2 编辑面板，详情：

- `POST /api/travel/v2/trips/{trip_id}/edits` 只接受单项结构化操作；服务端在 trip 行锁内读取当前 Revision、检查 CAS、应用变换并原子插入下个 Revision 与幂等记录。
- 操作覆盖地点添加/替换（候选来自现有腾讯 POI 查询）、活动添加、时间/时长/说明、删除、同日上移/下移、跨日移动、增删天数和交通方式。
- 编辑会重建受影响路段；新边和交通方式变化均不保留旧路线时长/距离/费用。有效路线事实仍保留在未变边上。
- 验证锁定/固定安排、顺序保护、时间冲突、已核实营业时间；预算缺少分项事实时写入复核提示，不伪造新的总价。
- UI 只在服务器返回保存成功后更新行程及 Revision；显示错误时保留已加载正式版本。CAS 冲突时重新读取服务器版本。上一 Revision 通过既有 restore API 撤销。
- POI 查询结果声明腾讯来源，营业时间与门票价格保持未知；查询失败与无结果分别显示。
