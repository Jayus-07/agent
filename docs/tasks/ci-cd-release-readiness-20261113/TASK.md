# CI/CD 生产发布验收修复

## 目标

完成并验证这条发布链路：PR 检查通过 → 合并 `main` → 按路径构建并推送镜像 → 核对镜像摘要 → 进入 `production` 环境审批 → 生产 runner 部署 → Release Gate 和发布记录通过。

## 范围

- 修复真实发布运行中暴露的构建身份不一致和门禁误判。
- 服务切换前检查生产数据库中的供应商密文能否由当前主密钥解开。
- 让模型、Worker、Prometheus 门禁验证实际就绪状态。
- 为关键行为补定向测试并纳入 `rag_smoke`。
- 保留现有生产审批、镜像摘要校验和回滚入口；不得绕过失败门禁。

## 验收

1. PR 必需检查通过，变更只经 PR 合并到 `main`。
2. 构建并推送的镜像身份、digest 和源码 SHA 一致。
3. 生产环境审批和生产 runner 部署实际完成。
4. 应用健康、模型调用、Worker 队列、观测目标和 Release Gate 均有真实证据；失败必须阻止发布并留下记录。
5. 回滚方式可用，未验证项不得标记为通过。

## 操作边界

- 不提交或打印生产密钥、API Key、密码及完整环境文件。
- 不在共享数据库上执行破坏性测试，不覆盖其他 Worktree 的运行服务。
- 所有代码经 PR 合入 `main`；提交分支前先展示 Diff 和验证结果并取得用户明确确认。
