# Task: 管理端信息架构（IA）与导航重构 (Phase 1)

## 1. 目标与背景
管理端目前存在页面繁多、业务边界模糊、监控子页面被伪装成侧边栏平级入口、业务告警与系统告警混淆等问题。
本任务旨在对管理端进行信息架构与导航重塑：
- 清晰划定业务域（业务运营、AI能力中台、运行调度、质量与可观测、安全与系统治理）；
- 消除监控工作台等多入口伪切页（将总览、Trace、网关、Token 等聚合为完整工作台入口）；
- 区分业务告警（商品库存预警）与基础设施服务告警（服务健康与告警）；
- 保留全部历史兼容路由 activePaths 与角色权限门禁（Viewer/Editor/Admin/部门主管）。

## 2. 交付与验收标准
- [ ] 侧边栏导航精简，去除同一工作台重复列出的 tab 伪入口；
- [ ] 语义清晰：库存告警重命名为“商品库存预警”并归入业务运营；
- [ ] 角色门禁 (visibleNav) 与深层路由激活 (getActiveNavLabel) 严格维持兼容；
- [ ] 前端定向单元测试 (`navConfig.test.ts`) 100% 通过；
- [ ] 前端构建 (`npm run build` 或 `vitest`) 通过，无类型与语法错误。
