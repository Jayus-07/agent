# 客服派单生产部署验收

## 目标

完成客服高并发派单与 RBAC 实施后的部署级验收，确认迁移、网关负载和故障恢复门禁有真实证据。

## 范围

- 在隔离或获批准的环境核对尚待应用的迁移链。
- 经 APISIX 网关执行负载验收，并在变更窗口内完成受控 dispatcher 故障演练。
- 保留已有代码与 PostgreSQL 并发验收结果；不得把它们当作尚未执行的部署级验收。
- 共享容器、数据库或端口操作前先确认其他会话未使用。

## 验收标准

- 迁移版本与部署数据库一致。
- 网关负载及故障演练达到实施方案门槛，且演练后服务和容器恢复正常。
- 结果、环境限制和未通过项写入 [PROGRESS.md](PROGRESS.md) 与证据文件。

实施方案：[客服高并发派单、RBAC 与登出实施方案.md](IMPLEMENTATION_PLAN.md)。

代码阶段已完成；部署级门禁仍待环境与变更窗口，详见 [PROGRESS.md](PROGRESS.md)。
