# 企业级 AI 评测平台 V2 改造

## 目标
依据交付包重构评测中心，并集成到现有管理端。八个功能区采用附件原型的信息架构和交互语义，颜色、字体基础与控件沿用管理端现有设计系统。真实数据、服务端状态与权限是唯一事实源；原型中的 Mock 分数、成功提示和浏览器 sessionStorage 不进入生产页面或评测决策。

## 范围
- 建立清晰的 evaluation_v2 后端领域边界、领域契约、PG schema、API、状态机、权限矩阵和回滚路径。
- 实现 CSV/JSONL 候选导入、预检、证据补全、并发审核、Golden 不可变发布与 hash、Suite 版本、语料快照引用。
- 以已有 Runner/任务系统作为执行 adapter，冻结 Run 输入，持久化逐例结果、有效性、Gate verdict 和审计；不重复实现评分算法或并列注册表。
- 将管理端改造成八区评测中心：运营概览、数据集中心、智能生成、标注审核、评测方案、实验运行、实验对比、发布质量。
- 兼容已有评测资产和历史 Run；旧模块只能作为迁移/执行 adapter，不得将 legacy_unverified 当已审核 Gold。
- 完成定向自动化验证、管理端真实浏览器验证、受影响后端服务本机重建与健康检查；所有未运行验证如实标记。

## 不在本任务中
- 不改动生产评测阈值、Provider 凭据、共享数据库中的业务数据或无关管理端页面。
- 不执行真实付费 L2/L3 评测或模型调用，除非它们已由现有批准机制显式授权。
- 不提交、不合并、不清理工作树；交付 Diff 与证据后等待用户决定是否提交。

## 持续施工路线

本任务按以下阶段连续推进；阶段内无外部依赖的实现、回归和文档同步一并完成，不逐项停下等待确认。只有缺少隔离语料、受保护凭据或真实服务等外部输入时，才标记具体阻塞，并继续做不依赖该输入的工作。

| 阶段 | 工作范围 | 完成条件 |
| --- | --- | --- |
| A. 无模型契约收口 | 修复 API 权限/状态缺陷；补充确定性契约与兼容测试；建立免费 PR CI；检查八区加载、错误恢复、无 Mock 成功态 | 测试和静态检查通过，CI 不注入 Provider 凭据，权限失败不会创建 Run/Task |
| B. 领域能力补齐 | 复用现有 Runner 接入 SQL、客服、旅游等已支持模块；明确 LLM Judge/人工评分校准所需数据；完成可离线验证的统计、Token/费用状态与失败语义 | 适配器不建平行 Runner；模型/费用未核实显示 `UNVERIFIED`；Judge 未校准前不得参与质量 Gate |
| C. RAG 真实运行闭环 | 使用已发布 Suite 和获授权隔离 KB，验证语料固定、异步 Run/恢复/取消、逐题详情、Experiment、Compare、Gate；浏览器使用真实 Gateway/JWT | 完整浏览器链路落库；worker 与 API 可访问同一不可变语料产物；故障保持 INVALID/BLOCKED，不产生虚假质量分 |
| D. 迁移与发布治理 | 旧历史映射、Run 多租户边界、跨库证据 TOCTOU、共享产物存储、CI/Git 发布审批、迁移回滚与恢复 | 旧资产状态明确；资源授权和租户边界有隔离验证；回滚可恢复且不会触碰共享数据 |
| E. 原型验收与交付 | 逐条执行 `SCENARIOS.md` 的 20 条场景，审阅完整 Diff、文档、健康状态和未验证风险 | 达到本文停止条件，或将剩余外部依赖按证据标成 BLOCKED/UNVERIFIED；保持未提交，等待用户决定提交 |

禁止以确定性 fake、无凭据 422、页面壳或单测通过替代 RAG 真实 Run；也禁止为消除阻塞而临时注入付费凭据、改生产阈值或触碰共享栈。

## 依赖顺序与验收
1. PR-A 架构：领域边界、ERD/API/状态机/权限、迁移与回滚。
2. PR-B 输入与审核：预检不写正式样本；候选需证据；Trace 原答只保存在 observed_answer；审核 CAS 与 append-only 审计。
3. PR-C Golden/Suite：发布事务、内容哈希、immutable 版本、版本差异、stale evidence。
4. PR-D Runner：异步/可恢复执行、幂等逐例结果、失败阶段、真实成本或 UNVERIFIED；Run 状态和 Gate verdict 分离。
5. PR-E 对比/Gate：不可比较原因、切片差异、安全硬否决、INVALID/BLOCKED 正确语义。
6. PR-F 管理端：八区真实 API 接线、响应式/无障碍/错误恢复、无 Mock 成功态。
7. PR-G 切换：入口兼容、历史数据迁移标记、备份与回滚。

## 停止条件
八个区域均能在现有管理端路由中打开；核心资产/审核/发布/运行/逐例结果/对比/Gate 流程从持久化 API 读取或写入；租户身份来自服务端可信上下文且授权按资源过滤；Golden/Suite/Run 快照不会漂移；真实运行故障不能伪装质量 PASS/FAIL；定向测试与可运行服务验证完成或按环境证据明确 BLOCKED/UNVERIFIED。只有这些条件满足后才将任务标记完成并向用户提交 Diff、结果和未完成风险。
