# 客服作品集改造任务

## 目标

为 Jayus-07/agent 客服域形成准确、可复现的作品集材料，说明受控业务流程、可靠执行和人工协同。稳定目标和资料入口见[作品集计划](../../customer-service/portfolio/portfolio-plan.md)。

## 范围

- 以当前客服代码、配置、Schema、迁移和通过的对应测试为事实源。
- T1：退款候选和资格判断共用结构化政策；RAG 不负责放行，政策不可用时写路径拒绝。
- T2：制作使用隔离模拟数据的端到端演示材料；人工裁决复用现有幂等 CLI 和运维手册，不绕过授权、审计或结果未知保护。
- T3：编写客服设计说明并记录固定提交下实际运行的评测证据。
- T4：说明模拟、未实现能力及生产化所需的权威数据、授权、审计和对账边界。

## 验收

- 文档只描述当前已实现的行为，规划项明确标为目标或未完成。
- 演示步骤可在获准隔离环境复现，不访问共享/生产数据库或触发未经授权的付费 Provider 调用。
- 退款申请、等待审核和资金退款的状态表述准确，不伪造资金操作成功。
- 评测证据包含提交、实际命令、环境、模型和样本范围；跳过或未运行的项目不标为通过。
- 相对链接和引用的代码路径有效；公共规范链接到既有客服域、运维和文档标准，不建立重复契约。

## 安全限制

- 不读取、复制或记录真实生产密钥。
- 不在共享数据库执行测试、迁移或运维裁决。
- 对副作用结果未知的操作保持阻断，按 `docs/operations/idempotency-runbook.md` 的授权流程处理。
- 真实 Provider 评测只在既有有效预算和授权范围内执行。
