## 6. 风险与纪律（新会话必读）

1. **多会话并行**：动手前 `git status` + `git log -3`；发现已有实施只做增量，不重写。
2. **提交一律路径限定**：`git commit -m ... -- <paths>`。否则会吞掉索引里**别人全部已暂存**的内容（本仓已实证发生过一次 76 项误吞）。
