## 五、本次执行的方法论沉淀（供后续复用）

1. **对"既有失败"也要实跑取证**——旧基线 104 failed 被误判为环境依赖，实跑发现真因完全不同
2. **Edit 锚点必须带函数级上下文**——同名代码行导致 `await` 插入同步函数，编译期才暴露
3. **config/__init__.py 是显式清单制**——加减常量必须同步 import 区 + `__all__` 两处
4. **LLM 非确定性输出必须内容寻址缓存**，否则会击穿下游一切基于内容的缓存
5. **Chroma `$ne` 对缺失字段不匹配**——补字段类过滤必须用"状态集合后过滤"，否则误杀全部存量数据
6. **先 grep 消费点再清理**——6 个死配置全部实证 0 消费后才删，避免误伤（CHUNK_SIZE 即在用）
