## 关键经验（避免下次重复踩坑）

1. **`uvicorn --reload` 经常卡住** → 必须 force kill + 干净启动（不验证 reload 成功 = 看日志的 `Started server process`）
2. **SSE 编码**：`ensure_ascii=True` 是最稳的（`\uXXXX` 转义，客户端 JSON.parse 还原）
3. **dict.pop 是破坏性读取** → SSE emit 前别 pop 业务字段
4. **Windows path**：`os.path.join` 不规范化 → 必须 `os.path.normpath`
5. **SSE 监听**：`onmessage` 只响应默认 message event（**无** `event:` 字段），用 `addEventListener('parsing', ...)` 接**特定** event
6. **重复文档**：必须明确告知用户（duplicate stage），不能"一闪而过"

详见 `sse-pipeline-debugging.md`。
