# 影子一致率模拟报告 + 标注复核排期（2026-09-19）

> 性质声明：本报告数据为**真实模拟运行**（种子集 52 条逐条执行 shadow_route
> 级联路由 vs 主路径统一抽取 LLM 预测），但**不是生产影子 7 天数据**——
> 切流决策（规划 §4 阶段 5/6）必须以生产影子 ≥10000 条样本为准。
> 本报告回答的问题是："**如果今天打开 METADATA_CASCADE_ENABLED，会发生什么？**"

## 1. 结论先行

**METADATA_CASCADE_ENABLED 必须保持关闭。** 模拟总体一致率仅 **73.1%**
（38/52）：打开级联后，约 27% 的上传文档 doc_type 会与现网主路径不同，
远超可接受水平（S2 门槛 = 影子准确率不得低于规则链 2pp；工程经验切流
门禁通常要求一致率 ≥95% 或准确率达标 +5pp）。

**主要问题在 L1 嵌入检索**：命中率低（7.7%）且命中的 4 条里 3 条判错
（一致率 25%）——阈值 0.60/0.05 是未调优初值，嵌入相似度分布实测偏松。
这与 embedding 压测 A2 FAIL（P95=338ms）共同指向：**L1 在当前形态下
既慢又不准，不值得开启**；L0（文件名/路径强先验）质量可接受（一致率
81%），L2 词表复核居中（64%）。

## 7. 基线可信度审计（2026-09-19 追加，回应"规则链识别不准"）

项目负责人指正种子基线 macro-F1=0.9206 偏乐观，复核确认存在**两层虚高**：

**虚高一：文件名信号循环（消融量化，`ablate_filename_signal.py` 可复跑）**
种子 gold 来自 fixture 文件名前缀，而规则链对文件名提示 +100 分（正文正则仅 4-10 分）——
两者共享信号源。消融结果：

| 形态 | accuracy | macro-F1 |
|---|---|---|
| 完整信号（文件名+路径+正文） | 0.83 | 0.92 |
| **纯正文信号（filename/path 传空）** | **0.77~0.79** | **0.82** |
| 文件名翻转预测 | 3/52（3 条均为"救回"） | |

**虚高二：样本偏斜（影响更大）**——种子集全是清晰命名 fixture；而线上主体是
模糊命名文档（skip 的 48 条）：规则链在其上的预测分布 financial 29% /
general 27% / security 12%，低置信(<0.7) 占 **38%**——这才是 traces 页
体感"不准"的形态。

**线上全量实锤（trace_store 2492 条索引 trace，trace 级去重）**：
- `llm_strategy` 中 `unified_extract` 仅 **8 次**，其余全是规则链策略标签——
  **prompt 断裂修复（§7.2 第 5 项）之前，线上 99.7% 的元数据出自规则链**，
  管理端看到的不准即规则链真实水平；
- doc_type 分布：policy 23% / faq 18% / financial 16% / legal 10% /
  **general 10%**；低置信(<0.7) 占 **20%**。

**对切流标准的修正**：规划 §1.2"≥ 规则链基线 +5pp"中的基线，正式测量时
**必须取纯正文信号形态（macro-F1 ≈0.82）而非完整信号（0.92）**——线上大量
文档没有语义文件名可蹭；且种子基线仅作管线试跑，正式基线以双人黄金集
（含模糊命名真实分布）为准。

**修复后展望**：prompt 修复已部署，统一抽取自 2026-09-19 起才第一次真正
作为主路径运行；其真实准确率将在黄金集基线（1.3）中首次得到量化。
