2. 每次改动后运行：`D:/Python/python.exe backend/scripts/validate_rag20k_decisions.py docs/evidence/rag20k/phase0/decisions/Q1-Q10.json`（blocked 退出 2，schema 错误退出 1，全部确认退出 0）。
3. 阶段 0 出口门（`backend/scripts/check_rag20k_phase0.py`）要求全部 confirmed 才放行决策项；任何 blocked 都会使阶段 0 保持未通过。
