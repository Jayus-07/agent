# 售后流程与异常件处理（模拟数据）

【模拟数据 · 内容虚构，仅供演示与评测，不得对客输出】

> 文档编号：DEMO-CN-AFTER-001　版本：v1.0　生效日期：2026-09-20　维护：演示店铺售后组
> 适用场景：怎么退货/换货、退货运费谁承担、退款多久到账、退货单号怎么填、质量问题、少发错发漏发、破损、过敏不适、超 7 天、保修维修。

## 一、退款时效

### 处理链路与时限

| 环节 | 时限 |
|---|---|
| 退款申请提交 → 客服审核 | 24 小时内（大促 48 小时） |
| 退回商品签收 → 仓库验收 | 2 个工作日 |
| 验收合格 → 发起退款 | 1 个工作日内 |
| 退款到账 | 见下表（自发起退款起算） |

### 到账时间（按支付渠道）

| 支付渠道 | 到账时间 |
|---|---|
| 支付宝 / 微信支付 / 银行卡 | 1-3 个工作日 |
| 信用卡 | 3-7 个工作日 |
| 花呗 | 1-3 个工作日（已分期订单需先结清分期） |

- 退款**原路退回**下单时使用的支付方式，平台**不支持更换退款渠道**。
- 若未在承诺时限内到账，可凭退款流水号联系客服升级核查。
- 大额退款（单笔 ≥1000 元）需主管复核，时效顺延 1-2 个工作日。

## 二、退货流程（用户视角）

1. 在「我的订单」点击「申请售后」→ 选择「退货退款」→ 填写退货原因、上传凭证（质量问题需图/视频）；
2. 客服审核通过后，页面显示**退货地址**与寄回要求（含包装、配件要求）；
3. 用户寄回商品，并在系统「填写退货单号」处录入快递单号（否则仓库无法关联，会延迟处理）；
4. 仓库签收后 2 个工作日内验收；
5. 验收合格 → 发起退款；验收不合格 → 原物寄回并说明原因（运费买家承担）。

### 常见问题

**Q：怎么填退货单号？**
路径：我的订单 → 售后详情 →「填写退货物流单号」→ 输入快递公司与单号 → 提交。若填错可联系客服更正。

**Q：退货地址给错了怎么办？**
在商品未寄出前联系客服重新提供地址；已寄出的需联系快递拦截或转寄，产生的费用按退货原因判定承担方。

**Q：退货运费谁承担？**
按原因判定：质量问题/发错货/物流破损 → **商家承担**；无理由/尺码不合适/拍错 → **买家承担**。完整矩阵见 `policy-return-exchange`。

**Q：可以只退款不退货吗？**
仅在特定场景支持（如低值商品质量问题、商家无法提供退货渠道时），需客服判定并记录，**不得随意承诺仅退款**。

**Q：退款退到哪里？**
原路退回原支付方式；组合支付（券+现金）时，券按平台规则返还（通常退回账户券包，且有有效期），现金原路退回。

## 三、换货与维修

### 换货

- 适用：尺码/颜色不合适、发错货、质量问题。
- 时效：仓库验收合格后 **48 小时**内发出新品。
- 限制：同一订单同商品仅换 **1 次**；无库存转退款。
- 运费：质量问题往返商家承担；无理由回程买家承担。

### 维修（保修）

| 步骤 | 说明 |
|---|---|
| 1. 报修 | 提供订单号 + 故障描述 + 故障视频/照片 |
| 2. 判定 | 客服初判：非人为故障且在保修期内 → 受理；人为损坏 → 提供付费维修报价 |
| 3. 寄回 | 提供维修地址，用户寄回（保修期内**往返运费商家承担**） |
| 4. 维修/换新 | 一般 7-15 个工作日；同型号故障 2 次以上可申请换新 |
| 5. 寄回用户 | 维修完成后寄回，附维修记录 |

- 保修期自签收日起算：电子类 12 个月、小家电 6 个月（以商品页标注为准，见 `product-guide`）。
- 不在保修范围：人为损坏（摔裂、进水、私拆）、耗材（耳罩垫、刀头密封圈）、超保修期。

## 四、异常件处理

### 少发 / 错发 / 漏发

| 情形 | 处理口径 |
|---|---|
| 漏发件（订单多件只收到部分） | 核对出库记录 → 确认漏发后 **48 小时内补发**，运费商家承担 |
| 错发（收到与订单不符商品） | 提供实物照片 → 商家承担运费换发正确商品，或退货退款 |
| 少发（数量不足） | 核对出库重量/记录 → 确认后补发差额 |
| 赠品漏发 | 核实后补发，不折现 |

> ⚠️ 用户主张漏发但出库记录显示已发齐时：需用户提供**外包装面单 + 开箱视频/照片**，无凭证时按协商处理，不得直接拒绝也不得直接赔付。

### 商品破损

1. 收集三图：**面单、外包装破损处、商品破损部位**；
2. 核对签收状态与时间（签收 48 小时内报备最佳）；
3. 轻微破损可协商部分退款补偿；严重破损补发或退货退款；
4. 责任在物流时向快递理赔，**不影响对用户的先行处理**；
5. 凭证齐全后 **24 小时内**给出方案。

### 过敏 / 不适合 / 不喜欢

| 原因 | 是否可退 | 运费 |
|---|---|---|
| 过敏（提供就医/症状凭证） | ✅ 可退 | 商家承担（个案审批） |
| 不适合自己（主观） | ✅ 7 天内可退 | 买家承担 |
| 不喜欢 / 不想要了 | ✅ 7 天内可退 | 买家承担 |

- 过敏类需先安抚并请用户停用；涉及健康损害的，**升级主管**处理，不得自行承诺赔偿金额。
- 已拆封的贴身/护肤类商品，主观原因不支持退货，质量或过敏原因除外。

### 超过 7 天还能退吗？

- 7-15 天：可协商，商品需完好，回程运费买家承担，需客服/主管审批；
- 超过 15 天：无理由退货不受理；质量问题按保修条款处理；
- 大促期间窗口延长至 15 天。

## 五、动作类问题（需系统能力，非知识回答）

| 用户诉求 | 正确处理方式 |
|---|---|
| 帮我退款 | 走售后流程（订单校验 → 资格判定 → 确认 → 执行），金额与状态以系统为准 |
| 帮我退货 | 生成退货单，返回真实退货地址 |
| 催退款进度 | 查售后单真实状态（待审核/待寄回/待验收/已退款） |
| 帮我补发 | 核实出库记录后创建补发单 |

> 原则：**退款金额、到账时间、售后单状态属事实性信息，必须来自系统；不得在无数据时推测或承诺「已处理」。**
