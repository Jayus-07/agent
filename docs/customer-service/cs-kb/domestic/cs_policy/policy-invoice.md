# 发票开具规则（模拟数据）

【模拟数据 · 内容虚构，仅供演示与评测，不得对客输出】

> 文档编号：DEMO-CN-POLICY-002　版本：v1.0　生效日期：2026-09-20　维护：演示店铺财务/客服部
> 适用场景：能否开票、票种选择、抬头税号、开票时间、补开与重开等财务类咨询。

## 一、开票基础规则

| 项目 | 口径 |
|---|---|
| 是否支持开票 | ✅ 全部订单支持开具发票 |
| 票种 | 电子普通发票、增值税专用发票 |
| 开票时机 | 订单**确认收货后**（或发货后）可申请；预售商品付尾款后 |
| 开票金额 | 按订单**实付金额**开具（不含优惠券抵扣部分）；运费如商家承担则并入开票金额 |
| 是否支持纸质票 | 默认只开电子票；确需纸质票请提供邮寄地址，快递费到付 |
| 开票主体 | 本店营业执照登记主体（发票专用章信息以开票主体为准） |

## 二、电子普通发票

- 申请方式：订单详情页 →「申请发票」→ 选择「电子普通发票」→ 填写抬头（个人/单位）→ 提交。
- 开具时效：提交后 **1-3 个工作日**发送至预留邮箱，也可在「我的-发票管理」下载 PDF。
- 个人抬头：填写姓名即可，无需税号。
- 单位抬头：需填写公司全称 + 纳税人识别号。

## 三、增值税专用发票

- 需提供资料（缺一不可）：
  1. 单位名称（与营业执照一致）；
  2. 纳税人识别号（15/18/20 位）；
  3. 注册地址与电话；
  4. 开户银行与银行账号。
- 开具时效：资料齐全后 **3-5 个工作日**；专票默认开具**电子专票**，如需纸质专票由财务寄出（顺丰到付）。
- 适用范围：一般纳税人企业；小规模纳税人请开普票。
- ⚠️ 开票资料错误（税号错、名称错）会导致对方无法抵扣，提交前请务必核对，客服不承担填错责任但可协助重开。

## 四、常见问题

### Q：能改抬头吗？

- **未开具**：可自行在「发票管理」修改抬头后提交。
- **已开具电子票**：电子发票不支持直接修改。处理方式：先在系统「申请红冲/作废」，作废后方可按新抬头重开（一般 1-3 个工作日完成）。
- **已开具纸质票且已寄出**：需寄回原发票后方可重开，往返邮费由买家承担。

### Q：能补开吗？

- 可以。超过开票窗口（一般订单完成后 90 天内）需联系客服登记，由财务人工补开，时限 3-5 个工作日。
- 超过 1 年的订单原则上不再补开，特殊原因需财务审批。

### Q：什么时候开？为什么还没收到？

- 开票需订单**确认收货**后触发；未确认收货的订单建议先确认收货。
- 电子票发送至**预留邮箱**，常见未收到原因：
  1. 邮箱填错（最常见）→ 核对后重新发送；
  2. 邮件被归入垃圾箱/推广邮件 → 提示用户检查；
  3. 开票高峰（月初、大促后）顺延 1-2 个工作日。
- 也可直接在「我的-发票管理」下载，无需等邮件。

### Q：税号怎么提供？在哪填？

- 申请发票页面有「纳税人识别号」输入框，直接填写即可。
- 不知道税号：可查营业执照左上角「统一社会信用代码」，或让公司财务提供。
- 个人/非企业订单**无需税号**。

### Q：退款的订单发票怎么处理？

| 情形 | 处理 |
|---|---|
| 未开票即退款 | 无需处理 |
| 已开电子普票后退款 | 系统自动红冲，用户无需操作 |
| 已开专票后退款 | 需用户配合确认红冲（专票需购方在税务端确认），否则影响退款进度 |
| 部分退款 | 按实付净额重开，或原票红冲后重开差额票 |

## 五、动作类问题（需系统能力，非知识回答）

| 用户诉求 | 正确处理方式 |
|---|---|
| 帮我开一张发票 | 转入开票申请流程（校验收货状态、抬头、税号），不得口头承诺已开 |
| 我的发票开了吗？ | 查发票管理接口返回真实状态（待开/已开/已发送） |
| 我要重开发票 | 走红冲/作废流程，需财务确认后重新开具 |

## 六、不得承诺（红线）

- 不得承诺「马上开」「立刻发你邮箱」——有 1-3 个工作日时效；
- 不得承诺「随便改抬头」——已开票需红冲；
- 不得承诺开票金额可高于实付金额（虚开属违法）。
