# 退换货政策总则（模拟数据）

【模拟数据 · 内容虚构，仅供演示与评测，不得对客输出】

> 文档编号：DEMO-CN-POLICY-001　版本：v1.0　生效日期：2026-09-20　失效日期：2027-09-19　维护：演示店铺客服部
> 适用场景：七天无理由、退货/换货条件、运费承担、运费险、超期退货等政策咨询。

## 一、七天无理由退货

### 基本规则

- 窗口：自**签收次日起 7 天（含）内**提出申请。
- 条件：商品**不影响二次销售**——
  - 保持吊牌完整、包装（含塑料袋/鞋盒/赠品）齐全；
  - 商品未经洗涤、使用、改装、损坏；
  - 含防伪码/防拆贴商品，防拆贴未撕毁。
- 退货运费：**无理由退货的回程运费由买家承担**。
- 退款：验收合格后原路退回（见 `aftersales-process` 退款时效）。

### 不支持七天无理由的商品

| 类别 | 说明 |
|---|---|
| 贴身衣物、内衣裤、袜子、耳塞类 | 已拆封的不支持 |
| 化妆品、护肤品、个护 | 已拆封/已使用的不支持 |
| 食品、生鲜、保健品 | 已拆封的不支持 |
| 定制类商品 | 定制款不支持 |
| 数字商品（激活码、会员） | 已激活的不支持 |
| 明确标注「不支持无理由」的清仓特价商品 | 页面标注为准 |

> 上述品类若存在**质量问题**，仍可正常退换，不受此限。

## 二、运费承担规则

| 退货原因 | 运费承担方 |
|---|---|
| 质量问题（破损、故障、面料缺陷、染色不均） | **商家承担**（含往返） |
| 发错货、漏发、少发 | **商家承担**（含往返） |
| 物流破损、丢件 | **商家承担**（含往返） |
| 七天无理由：不喜欢、不合适、拍错、颜色主观色差 | **买家承担**（回程） |
| 尺码不合适 | **买家承担**（回程） |
| 地址填错/超时未取导致退回 | **买家承担** |

- 商家承担的运费与货款一并退回；
- 买家承担的运费不退（如订单包邮，退货运费由买家自理）；
- 活动期使用运费券/免邮的订单，退款按**实付运费**口径计算，活动抵扣金额不折现。

## 三、运费险

- 商品页面标注「含运费险」的订单，退货时由保险公司赔付**首重运费**（一般 8-12 元，以保单为准）。
- 运费险在**申请退货后自动生效**，无需单独操作；赔付款在退货签收后 1-3 个工作日到账。
- 未标注运费险的商品无此保障；运费险不支持单独购买或事后补投。
- 运费险赔付不包括：超重部分、保价费、买家主动选择的加急费用。

## 四、换货规则

- 支持换货的场景：尺码/颜色不合适、发错货、质量问题。
- 换货流程：「申请换货」→ 寄回原商品（或商家先补发，视信用与商品价值）→ 商家验收 → 发出新商品。
- 换货时效：验收合格后 **48 小时内** 发出新品。
- 限制：同一订单同商品**仅支持换货 1 次**；换货商品无库存时转退货退款处理。
- 无理由换货：回程运费买家承担；质量问题换货：往返运费商家承担。

## 五、超期与例外

| 情形 | 处理口径 |
|---|---|
| 超过 7 天但未超 15 天 | 可协商，需商品完好；往返运费买家承担，且需客服/主管审批 |
| 超过 15 天 | 无理由退货不受理；质量问题按保修条款处理 |
| 大促期间（双11/618） | 无理由退货窗口延长至 **15 天**（以活动公告为准） |
| 商品已下架/停产 | 退货退款正常受理；换货转退款 |

## 六、退换货流程概览

1. 用户在「我的订单」点击「申请售后」，选择退货/换货/仅退款，填写原因并上传凭证；
2. 客服审核（一般 **24 小时内**），通过后提供退货地址与要求；
3. 用户寄回商品并在系统填写**退货单号**；
4. 商家仓库签收验收（**2 个工作日**内）；
5. 验收合格 → 发起退款 / 发出换货商品；
6. 验收不合格（影响二次销售）→ 退回商品，运费由买家承担，并告知原因。

> 详细执行细节见 `aftersales-process`（售后流程与异常处理）。

## 七、不得对外承诺的表述（红线）

- 不得承诺「无条件退货」「随便退」「多久都能退」；
- 不得承诺「一定免运费」，需先判定原因；
- 不得承诺「立即到账」，退款有时效；
- 不得为规避纠纷自行垫付或承诺额外补偿，需走审批。
