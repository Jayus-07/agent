# 活动价格、保价与配送时效政策（模拟数据）

【模拟数据 · 内容虚构，仅供演示与评测，不得对客输出】

> 文档编号：DEMO-CN-POLICY-003　版本：v1.0　生效日期：2026-09-20　维护：演示店铺运营/客服部
> 适用场景：保价、降价退差、大促规则、优惠券叠加、满减、限购、赠品、补货等价格与活动类咨询；附配送与发货时效。

## 一、保价与降价退差

### 保价规则

| 项目 | 口径 |
|---|---|
| 是否支持保价 | ✅ 支持价格保护 |
| 保价窗口 | 下单后 **15 天内**（自付款日起算） |
| 适用前提 | 同一商品、同一规格、同一店铺，在保价期内出现**页面直降** |
| 不适用情形 | 优惠券/红包/平台补贴导致的到手价差、秒杀/限量特价、会员专属价、赠品差异、已退货订单 |
| 退差方式 | 联系客服申请，核实后以**无门槛红包/原路退还差价**方式补偿，1-3 个工作日处理 |
| 上限 | 单笔订单退差不超过实付金额的 30% |

### 常见问法

**Q：我刚买就降价了怎么办？**
亲，我们支持 15 天价格保护。麻烦提供订单号，我帮您核实一下是否在保价期内、是否同一规格，符合条件的话可以申请退差价～

**Q：保价是自动的吗？**
不是自动的，需要您联系客服申请。若在保价期内系统检测到降价，部分订单会推送提醒，但**不保证每条都推送**，建议您主动联系。

**Q：用了优惠券买的还能保价吗？**
优惠券、红包等优惠导致的价差不属于保价范围；保价只针对商品页面价格直降。

## 二、大促规则（618 / 双 11）

| 项目 | 口径 |
|---|---|
| 活动时间 | 以页面公告为准，预热期与正式期价格可能不同 |
| 预售与现货差异 | 预售可能比现货便宜，也可能更贵（赠品不同），以各自页面标价为准 |
| 无理由退货窗口 | 大促期间延长至 **15 天** |
| 发货时效 | 大促期间顺延至付款后 **72 小时**内发出 |
| 保价 | 大促价保同样适用 15 天窗口；但**大促当天特价与秒杀价不参与保价** |
| 价格计算 | 大促成交价 = 商品活动价 − 优惠券 − 满减 − 红包（以结算页最终显示为准） |

**Q：双11 的活动怎么算？现在买还是等活动？**
活动价与玩法以活动页面公告为准，客服无法提前透露未公布的价格。建议您关注商品页「降价提醒」，活动开始会推送通知。

## 三、优惠券与满减

| 问题 | 口径 |
|---|---|
| 能叠加吗？ | 店铺券与平台券可**各用 1 张**（共 2 张）；同类券不可叠加；折扣券与满减券是否叠加以结算页为准 |
| 满减怎么用？ | 满减按**店铺活动价**计算门槛，如「每满 300 减 50」，可跨商品累计 |
| 用了券还能保价吗？ | 券导致的价差不在保价范围 |
| 券过期能用吗？ | 不能，过期券不补发（平台原因导致的异常除外） |
| 券为什么用不了？ | 见 `faq-presale-ordering` 的「优惠券为什么用不了」 |
| 券能换现金吗？ | 不能 |

## 四、限购、秒杀与补货

| 问题 | 口径 |
|---|---|
| 为什么限购？ | 活动商品为保障更多用户买到，限量（常见每单 2 件/每人 5 件），**不能多拍** |
| 秒杀没抢到怎么办？ | 秒杀库存有限，售完即止；可关注下一场次或加入「到货通知」 |
| 库存没了还会补吗？ | **不承诺补货**。可点击「到货通知」，补货后系统推送提醒 |
| 能预留库存吗？ | 不支持预留、不支持锁库存 |

## 五、赠品规则

- 赠品以**下单时页面标注**为准（标注「赠」的商品会随单发出）。
- 赠品漏发：核实订单后**补发**（赠品不折现、不换现金）。
- 赠品不支持单独退换；退货时需将赠品一并退回，否则按赠品价值扣除。
- 赠品数量有限，赠完即止，活动结束后下单不再附赠。

## 六、配送与发货时效汇总

| 环节 | 时效 |
|---|---|
| 付款后发货 | 现货 48 小时内；大促 72 小时内；预售按详情页标注 |
| 揽收信息更新 | 交快递后 12-24 小时出现首条轨迹 |
| 在途时效 | 普通快递 3-5 天；江浙沪 1-2 天；偏远 5-8 天（新疆/西藏部分地区 8-12 天） |
| 顺丰加急 | 1-3 天（买家补差价） |
| 包邮门槛 | 实付满 99 元全国包邮（偏远地区除外） |
| 偏远加收 | 新疆、西藏、青海、内蒙古部分区域 +15 元 |

## 七、不得承诺（红线）

- 不得承诺「以后一定不会降价」「买了就保价」；
- 不得承诺「一定补货」「帮你留一件」；
- 不得承诺超出 15 天窗口的保价，或超上限（30%）的退差；
- 不得私自修改订单价格、私下发券、绕过平台规则补贴用户。
