> 适用场景：售前咨询（有货/发货/快递/正品/尺码/材质/优惠/无理由）与下单支付环节。

## 一、售前咨询

### Q：在吗？有人吗？

在的，亲，您好～请问有什么可以帮您的？

### Q：有货吗？什么时候发货？

- 现货商品：商品详情页显示「现货」即表示有货，拍下即可，**48 小时内发出**。
- 预售商品：以详情页标注的发货时间为准（常见为付尾款后 7 天 / 15 天内发出）。
- 若商品显示「缺货」：暂不支持下单，可点击「到货通知」，补货后系统会推送提醒。

### Q：发什么快递？包邮吗？能指定快递吗？

| 项目 | 口径 |
|---|---|
| 默认快递 | 中通 / 圆通随机发货（系统自动匹配，不支持指定） |
| 包邮门槛 | 单笔订单实付满 **99 元** 全国包邮（新疆、西藏、内蒙古部分地区除外） |
| 偏远地区 | 新疆、西藏、青海、内蒙古部分区域加收 **15 元** 运费，下单页会显示 |
| 指定快递 | 不支持指定快递公司；如确需顺丰可联系客服，顺丰差价由买家承担（顺丰到付） |

### Q：是正品吗？有授权吗？有质检报告吗？

- 本店为品牌**官方授权店铺**，全部商品正品保障，支持专柜验货。
- 商品页「资质」栏可查看品牌授权书与质检报告（部分品牌报告仅对该批次有效，可联系客服索取当前批次报告）。
- 承诺：**假一赔十**。

### Q：尺码怎么选？偏大还是偏小？

- 每款商品详情页均有**尺码对照表**（含衣长/胸围/肩宽/建议身高体重）。
- 通用建议：按平时穿着尺码下单；详情页标注「偏小」的商品建议拍大一码。
- 不确定时请提供身高、体重、平时穿的尺码，客服会给出具体建议（见 `product-guide` 商品知识库）。

### Q：材质是什么？会掉色吗？会起球吗？

- 材质成分标注在商品详情页「面料成分」栏，以标注为准。
- 深色纯棉商品**首次下水轻微浮色属正常现象**，建议单独冷水手洗、避免暴晒。
- 起球说明：卫衣/毛呢类天然纤维面料摩擦部位可能出现轻微起球，属面料特性，非质量问题；可用毛球修剪器处理。如大面积起球可申请售后。

### Q：和图片一样吗？有色差吗？

- 商品为实物拍摄，但因**显示器色差、拍摄光线**差异，实物颜色可能与图片存在轻微差异，不属于质量问题。
- 若色差明显（如收到颜色与页面标注颜色不一致），可申请退换，运费由商家承担。

### Q：适合我吗？孕妇/敏感肌/儿童能用吗？

| 人群 | 口径 |
|---|---|
| 孕妇 | 体脂/称重类商品**不建议**孕妇使用体脂功能（测量方式为生物电阻抗）；普通称重功能可用。护肤类商品使用前请查看成分表并咨询医生 |
| 敏感肌 | 建议先在耳后/手腕内侧小面积试用；如出现不适请立即停用。因个体差异导致的不适不属于质量问题，但可在 7 天内申请退货 |
| 儿童 | 标注「儿童适用」的商品可正常使用；电子类商品（暖手宝、榨汁杯）**儿童需在成人监护下使用**，刀头类商品请勿让儿童单独操作 |

### Q：有优惠吗？能便宜点吗？有赠品吗？

- 商品页价格已为**当前活动价**，客服**无权修改订单价格**。
- 可领取店铺优惠券下单（领券入口在商品页/店铺首页），券后价以下单页显示为准。
- 赠品：下单时页面标注「赠」的商品会随单发出，赠品不单独补发（漏发除外，见售后文档）。
- 议价请求统一回复：价格已是活动最低价，暂时无法再优惠，可以领券更划算。

### Q：支持七天无理由吗？有运费险吗？

- 支持**7 天无理由退货**（自签收次日起计算），需保证不影响二次销售。
- 运费险：部分商品页面标注「含运费险」，退货时由保险公司赔付首重运费；未标注的商品无运费险。
- 详细条件见 `policy-return-exchange`（退换货政策）。

### Q：能开发票吗？

可以。支持电子普通发票与增值税专用发票，下单时或收货后均可申请。详见 `policy-invoice`（发票规则）。

## 二、下单与支付

### Q：怎么下单？

1. 选择商品规格（颜色/尺码/数量）→ 点击「立即购买」或「加入购物车」；
2. 确认收货地址、优惠券、配送方式 → 提交订单；
3. 在支付页选择支付方式并完成付款；
4. 付款成功后订单状态变为「待发货」。

### Q：为什么下不了单？支付失败怎么办？

| 现象 | 原因与处理 |
|---|---|
| 提示「商品已下架」 | 商品售罄或链接失效，可联系客服推荐同款 |
| 提示「超出限购」 | 活动商品限量（常见每单 2 件），请减少数量或分单 |
| 支付失败 | 依次尝试：①更换支付方式（微信↔支付宝↔银行卡）②更换网络（WiFi↔4G/5G）③退出重进后重新提交 ④ 确认银行卡余额/单笔限额 |
| 重复扣款 | 系统一般 1-3 个工作日自动原路退回，无需着急；超时未退请联系客服核单 |
| 库存已锁定但未付款 | 订单 30 分钟内未付款将自动取消，库存释放，可重新拍下 |

### Q：能用花呗/信用卡/微信支付吗？

- 支持：微信支付、支付宝、支付宝花呗、信用卡（含分期，部分商品支持 3/6/12 期免息，以商品页标注为准）、储蓄卡。
- 不支持：货到付款（除部分标注「支持 COD」的商品）、虚拟币、私人转账。

### Q：可以货到付款吗？

- 平台**默认不支持货到付款**。
- 仅在商品详情页明确标注「支持货到付款」且收货地址在支持区域内时可选择 COD。下单页无该选项即表示不支持。

### Q：能改地址、改尺码、改颜色吗？

- **未发货**：订单信息不支持直接修改，需取消原订单后重新拍下（库存会短暂释放，建议先确认有货再取消）；如仅需改收货地址，可联系客服尝试在仓库发货前拦截修改（不保证成功）。
- **已发货**：无法修改订单信息，可联系快递改派（可能产生改派费用），或拒收后重新下单。

### Q：能合并订单吗？能取消订单吗？

- 合并订单：不支持合并；同一地址的两笔订单会由仓库尽量同包裹发出，但不承诺。
- 取消订单：**未发货**可自行在订单详情页点击「取消订单」，付款将原路退回；**已发货**需走「申请退货」或拒收流程。

### Q：优惠券为什么用不了？

| 常见原因 | 说明 |
|---|---|
| 未达门槛 | 如「满 199 减 30」，订单实付需满 199 元 |
| 品类不适用 | 部分券限指定品类/指定商品，详情见券面说明 |
| 已过期 | 券有使用期限，过期不可恢复 |
| 互斥 | 特价商品、秒杀商品可能不参与用券 |
| 张数限制 | 单笔订单最多使用 1 张店铺券 + 1 张平台券，同类型券不可叠加 |

## 三、动作类问题（需系统能力，非知识回答）

以下问题**不属于知识库可答范围**，需要订单/物流/售后系统提供实时数据或执行动作。知识库只提供口径与话术，不得凭空编造结果：

| 用户诉求 | 正确处理方式 |
|---|---|
| 我的订单到哪了？ | 调用订单/物流查询接口，返回真实轨迹（无数据时必须说明查不到，不得编造） |
| 帮我催一下发货 | 校验订单状态后创建催件记录，回复已催件，不承诺具体时间 |
| 帮我改地址 | 转入地址修改流程（未发货可试拦截，已发货转快递改派） |
| 帮我退款/取消订单 | 转入售后/取消流程，需身份与订单校验，金额与状态以系统为准 |
| 我的优惠券有几张？ | 查询账户券包，无接口时引导用户到「我的-优惠券」自查 |

> 原则：**涉及订单状态、金额、退款结果的事实必须来自系统或知识证据，禁止推测填空。**
