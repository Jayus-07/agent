# 物流发货与账号地址 FAQ（模拟数据）

> 文档编号：DEMO-CN-FAQ-002　版本：v1.0　生效日期：2026-09-20　维护：演示店铺客服部
> 适用场景：物流发货咨询（发货时效/快递/轨迹异常/改址/驿站/丢件破损/签收未收到）与账号地址问题。

## 一、发货时效

| 商品类型 | 发货时效 |
|---|---|
| 现货商品 | 付款后 **48 小时内** 发出（大促期间顺延至 72 小时） |
| 预售商品 | 详情页标注为准，常见「付尾款后 7 天内」或「15 天内」 |
| 定制商品 | 下单后 3-7 个工作日发出 |
| 跨境保税商品 | 清关后 48 小时内发出，整体到手 5-15 个工作日 |

- 发货时间以**物流揽收时间**为准（不是下单时间，也不是打印面单时间）。
- 急用可备注「急用」，仓库会优先拣货，但**不承诺加急时效**。
- 节假日、大促（618/双11）期间仓库压力大，时效普遍顺延 1-3 天。

## 二、物流查询

### Q：发货了吗？单号多少？

- 订单状态变为「已发货」即表示包裹已交给快递。
- 物流单号在「我的订单 → 订单详情」可见，也会通过站内信/短信推送。
- ⚠️ 单号查询结果必须以**真实物流接口返回**为准；若接口暂无数据，回复「物流信息尚未更新」，**不得编造轨迹**。

### Q：为什么物流不动了？

| 现象 | 常见原因 | 处理口径 |
|---|---|---|
| 刚发货无轨迹 | 快递揽收后需 12-24 小时上传首条轨迹 | 告知正常，等 24 小时后再看 |
| 中途停滞 2-3 天 | 干线运输中转、分拨中心积压 | 告知正常运输中，可代为催件 |
| 停滞超过 3 天 | 可能丢件或异常 | **创建催件工单**，物流商 1-2 个工作日反馈 |
| 显示「派送失败」 | 收件人不在/电话不通/地址不详 | 引导联系快递员或申请二次派送 |
| 显示「已签收」但没收到 | 可能被他人代收、放驿站/快递柜 | 先查驿站与快递柜，再联系快递核实 |

- 停滞超过 **7 天**：可申请补发或全额退款（二选一，以物流责任认定为前提）。
- 停滞超过 **15 天**：视为丢失，可发起理赔，商家先行退款或补发。

### Q：多久能到？能加急吗？

| 配送方式 | 时效（发货后起算） |
|---|---|
| 普通快递（包邮） | 3-5 天（江浙沪 1-2 天） |
| 偏远地区 | 5-8 天（新疆/西藏部分地区 8-12 天） |
| 顺丰（买家补差价） | 1-3 天 |

- 不支持指定送达时间；如需指定日期收货，建议到货前联系快递预约派送。
- 「加急」仅指仓库优先发货，不改变快递在途时效。

### Q：能改地址/电话吗？能指定时间送吗？

- **未发货**：可联系客服尝试修改收货信息，仓库未出库前拦截成功率较高，**不保证成功**。
- **已发货**：无法修改系统订单，只能联系快递协商改派（可能产生改派费，由买家承担）。
- **指定时间送**：可在派送前直接联系快递员约定时间，平台侧无法设定。
- 涉及手机号、姓名变更时，需核验订单归属（防范冒改）。

### Q：能放驿站/快递柜吗？

- 下单时可在地址备注「放驿站/快递柜」，快递员一般会按备注投递。
- 已发货后可在快递小程序/短信链接中直接修改投递方式。
- ⚠️ 驿站/快递柜**超时未取（一般 3 天）会被退回**，退回产生的运费由买家承担。
- 生鲜、贵重物品、大件商品**不支持驿站代收**，需本人签收。

## 三、物流异常处理

### Q：快递丢件、破损了怎么办？

处理流程（缺一不可）：

1. 让用户提供三张图：**快递面单**、**外包装（含破损处）**、**商品实物/问题部位**；
2. 客服核对订单号与签收状态；
3. 破损：按商品损坏程度协商补发、换货或退款（**往返运费商家承担**）；
4. 丢件：向快递发起查件/理赔，同时**先行**为用户补发或退款；
5. 记录异常单号并同步仓库，避免重复发货。

> 时效承诺：破损凭证齐全后 **24 小时内**给出处理方案。

### Q：显示已签收但我没收到怎么办？

1. 先确认是否被家人/门卫/驿站/快递柜代收；
2. 未找到：联系快递公司核实签收记录（可要求提供签收底单）；
3. 快递无法证明本人签收的，由商家协调理赔，并**先行补发或退款**；
4. 核实期间商品需保留，勿自行丢弃包装。

## 四、账号与地址

### Q：登录不上/密码忘了怎么办？

- 密码遗忘：登录页点击「忘记密码」→ 输入注册手机号 → 短信验证码校验 → 设置新密码（8-20 位，含字母与数字）。
- 手机号已停用：需联系客服走人工身份核验（提供订单号 + 收货人姓名 + 常用地址），核验通过后协助更换绑定手机号。
- 提示账号异常：可能触发风控，请等待 30 分钟或联系客服解除。

### Q：怎么修改收货地址？

- 路径：「我的 → 收货地址 → 编辑」，可新增、修改、删除地址，并设置默认地址。
- 下单时可在确认页临时选择其他地址（不修改默认地址）。
- 修改**已提交订单**的地址见上文「能改地址吗」。

### Q：地址填错了，订单已经提交了？

- 未发货：联系客服拦截修改，或取消重拍；
- 已发货：联系快递改派；
- ⚠️ 地址错误导致包裹退回或丢失，运费与损失由买家承担。

## 五、动作类问题（需系统能力，非知识回答）

| 用户诉求 | 正确处理方式 |
|---|---|
| 我的包裹到哪了？ | 调物流接口返回真实轨迹，无数据就答「未更新」 |
| 帮我催一下快递 | 校验订单后创建催件工单，回复「已催件，有进展会同步」 |
| 修改收货地址 | 走地址修改流程；已发货转快递改派 |
| 我的地址列表 | 调账户地址接口，或引导用户到「我的-收货地址」自查 |
