# 投诉处理与红线管理（模拟数据）

【模拟数据 · 内容虚构，仅供演示与评测，不得对客输出】

> 文档编号：DEMO-CN-COMPLAINT-001　版本：v1.0　生效日期：2026-09-20　维护：演示店铺客服主管组
> 适用场景：我要投诉、要给差评、曝光、找 12315、要求赔偿、要求升级主管、加微信、线下交易、做代理等。

## 一、投诉处理基本原则

1. **先情绪，后问题**：先安抚道歉，再处理事实，不在用户情绪激动时讲规则。
2. **只承诺能交付的**：不承诺删差评、不承诺具体赔偿金额、不承诺「一定满足」。
3. **留痕**：所有投诉必须记录（用户诉求、订单号、处理动作、结果），便于复盘与升级。
4. **升级优先于硬扛**：涉及赔偿、健康损害、媒体曝光、法律途径时，立即升级主管，不自行拍板。

## 二、分级与响应

| 等级 | 触发情形 | 处理要求 |
|---|---|---|
| L1 一般不满 | 抱怨质量、物流慢、服务态度（无威胁性表述） | 客服首次响应即处理，24 小时内给方案 |
| L2 明确投诉 | 明确说「投诉」「给差评」「找平台」 | 记录工单，客服主管 4 小时内介入 |
| L3 高风险 | 要求赔偿、称身体损害、曝光媒体、找 12315/消协、称将起诉 | **立即升级主管**，30 分钟内响应，保护性措施（先退款/先补发）可先行 |
| L4 危机 | 涉及人身安全、群体投诉、监管介入、大规模舆情 | 升级至运营负责人 + 法务/合规，客服不单独回应定性问题 |

## 三、典型场景应答

### Q：我要投诉！我要给差评！

亲，非常抱歉给您带来这么不好的体验，这确实是我们的问题。我已经把您的情况记录下来了（工单号 XXX），会由主管优先跟进处理。
关于评价，我理解您的心情——不过我更希望能真正把问题解决掉，您方便的话告诉我具体遇到什么情况，我马上帮您处理/申请补偿。

- ✅ 可说：抱歉、记录、跟进、给方案、申请补偿
- ❌ 不可说：求你删差评、给钱删评价、差评无所谓/随便你评

### Q：能赔偿吗？

亲，我特别理解您的心情。赔偿需要根据实际情况和规则来判定，我先帮您把情况记录下来，由主管为您申请合理的解决方案，稍后会有专人联系您，好吗？

- 赔偿口径：轻微问题 → 无门槛券/小额补偿（需审批）；涉及损失 → 主管审批；涉及健康损害 → **升级处理，客服不得自行承诺金额**。
- 不得承诺：超出权限的现金赔偿、精神损失费、误工费等无法定依据的赔偿。

### Q：我要曝光 / 找 12315 / 找消协 / 起诉你们

亲，非常抱歉让您不满到这个程度。您的诉求我已经完整记录，我们会按平台规则和相关法规为您处理。也请您相信我们会认真对待。

处理口径：

- 不争辩、不阻拦用户依法维权（**不得**说「你投诉也没用」）；
- 立即升级 L3，记录用户明确表达的维权渠道；
- 备齐证据材料（订单、物流、沟通记录、凭证），以备平台/监管核查；
- 由主管或指定人员统一对外回应，一线客服不自行解释法律问题。

### Q：能加微信吗？能线下交易吗？

亲，非常抱歉，为了保障您的资金安全和售后权益，平台规定不支持私下加微信或线下交易哦～ 通过平台下单可以享受平台保障和售后，也方便您随时查询订单。有需要我在这儿随时帮您～

- **红线**：不提供个人微信/电话/收款码；不引导脱离平台交易；不索要或代付私人款项。
- 原因（可对内说明）：脱离平台交易无售后保障、易发生资金诈骗、违反平台规则会被处罚。

### Q：能做代理吗？能合作吗？

亲，感谢您的认可～ 合作/代理事宜这边需要走商务渠道，我帮您登记一下联系方式，由商务同事在 1-2 个工作日内联系您，可以吗？

- 不承诺合作条件、价格、独家权限；不提供内部成本价、供货价。
- 不泄露供应商、进货渠道等商业信息。

### Q：催发货、催退款、催处理

亲，我帮您催一下，有进展第一时间回复您～

- 催件/催退款必须**真实产生动作**（创建催件记录或查询真实状态），不做口头安抚式回复；
- 不承诺具体时间点，只承诺「有进展会同步」。

## 四、升级路径

```
一线客服
  ├─ 可直接处理：解释规则、道歉、登记、催办、小额券补偿（权限内）
  ├─ 升级客服主管：赔偿申请、超权限退款、L2/L3 投诉、评价纠纷
  ├─ 升级运营/售后负责人：L4 危机、批量投诉、重大金额、监管介入
  └─ 升级法务/合规：人身损害、诉讼、媒体曝光、合规性质疑
```

- 升级后原客服**不得继续与用户协商超出原方案的内容**，避免口径冲突。
- 升级需附：订单号、问题摘要、用户诉求、已做动作、建议方案。

## 五、评价管理口径

| 情形 | 口径 |
|---|---|
| 用户给了差评 | 主动联系了解原因，解决问题后礼貌请求修改评价（**不施压、不诱导、不付费**） |
| 用户以差评索要补偿 | 视为 L2/L3 处理，记录证据，按规则申请方案，**不得因威胁而超权限补偿** |
| 好评邀请 | 仅在服务完成后礼貌邀请，不频繁打扰 |

## 六、红线清单（违反即严肃处理）

- ❌ 承诺删差评 / 付费买好评 / 诱导修改评价
- ❌ 私自加微信、引导线下交易、提供个人收款方式
- ❌ 辱骂、嘲讽、与用户争吵、泄露用户隐私
- ❌ 泄露供应商、成本价、内部政策等商业信息
- ❌ 超权限赔偿承诺或绕过审批垫付
- ❌ 编造处理结果（未查就说已查、未做动作就说已办）
