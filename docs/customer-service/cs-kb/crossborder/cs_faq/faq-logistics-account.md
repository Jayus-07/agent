# 物流发货与账号地址 FAQ（跨境 · 模拟数据）

【模拟数据 · 内容虚构，仅供演示与评测，不得对客输出】

> 文档编号：DEMO-XB-FAQ-002　版本：v1.0　生效日期：2026-09-20　维护：演示跨境店铺客服部
> 适用场景：跨境物流查询（轨迹停滞/清关/派送失败/丢件破损/签收未收到）与账号地址问题。
> 物流异常判定标准以 `policy-logistics-exception.md` 为准，本文件与其保持一致。

## 一、发货与物流查询

### Q：发货了吗？单号多少？

- 订单状态变「已发货」即代表已交承运商；国际单号在订单详情可见，并同步站内信/邮件。
- 跨境包裹通常包含**两段单号**：国内段 + 目的国段，后半段轨迹可能延迟出现。

### Q：为什么物流不动了？

按 `policy-logistics-exception.md` 判定：

| 异常类型 | 判定标准 | 处理 |
|---|---|---|
| 轨迹停滞 | 超过 **3 天**无更新（跨境干线运输段放宽至 **5 天**） | 满足条件可创建催件工单 |
| 派送失败 | 派送 **2 次**未成功，包裹滞留派送站 | 联系用户确认地址/约二次派送 |
| 清关滞留 | 目的地清关超过 **48 小时** | 协助催清关，提示用户留意缴税通知 |
| 疑似丢失 | 轨迹停滞超过 **15 天** | 按丢失处理 |

- 催件条件（满足任一）：已发货且停滞 ≥3 天（干线 ≥5 天）；显示派送失败且滞留 >24 小时；承诺送达时间已过 48 小时仍未签收。
- 处理时限：创建催件工单后承运商 **1-2 个工作日**反馈。
- 停滞超过 **7 天**：可申请补发或全额退款（二选一）。
- 确认丢失（停滞超 **15 天**）：自动触发全额退款，无需买家申请。

### Q：多久能到？能加急吗？

- 在途时效参考 `faq-presale-ordering.md`（美国/加拿大 7-12 工作日；欧洲 7-15 工作日；日韩新 5-10 工作日）。
- 不支持指定送达时间；「加急」仅指仓库优先发货，不改变跨境在途时效。

### Q：能改地址/电话吗？能指定时间送吗？

- **未发货**：可联系客服尝试拦截修改，不保证成功。
- **已发货**：只能联系承运商改派，可能产生改派费；跨境包裹改派成功率低于国内。
- **指定时间**：可在派送前联系当地承运商约定，平台侧无法设定。
- ⚠️ 跨境订单地址填错导致退运，**往返运费及关税损失由买家承担**。

### Q：能放驿站/快递柜/代收点吗？

- 跨境段通常由目的地邮政/本地快递派送，可尝试投递至代收点（Pickup point）。
- 无法投递或超时未取会**退回发件地**，退运费用由买家承担。
- 贵重物品与高值订单**要求本人签收**，不支持代收。

## 二、物流异常处理

### Q：快递丢件、破损了怎么办？

处理流程：

1. 收集凭证：**运单/面单**、**外包装（含破损处）**、**商品实物/问题部位**照片；
2. 客服核对订单与签收状态；
3. 破损：按损坏程度协商补发、换货或退款，**往返运费商家承担**（见 `policy-shipping-fee.md`）；
4. 丢件：向承运商发起查件/理赔，同时**先行**为用户补发或退款；
5. 记录异常单号同步仓库，避免重复发货。

> 时效：凭证齐全后 **24 小时内**给出处理方案。

### Q：显示已签收但我没收到怎么办？

1. 先确认是否被家人、门卫、代收点代收；
2. 联系当地承运商核实签收记录（可要求提供签收底单）；
3. 承运商无法证明本人签收的，由商家协调理赔，**先行补发或退款**；
4. 保留外包装，勿自行丢弃。

## 三、账号与地址

### Q：登录不上 / 密码忘了怎么办？

- 忘记密码：登录页「Forgot password」→ 输入注册邮箱/手机号 → 收验证码 → 设置新密码（8-20 位，含字母与数字）。
- 邮箱已停用：需人工身份核验（订单号 + 收货人姓名 + 常用地址 + 支付凭证后四位），核验通过后协助更换绑定方式。
- 提示账号异常：可能触发风控，请等待 30 分钟或联系客服解除。

### Q：怎么修改收货地址？

- 路径：我的 → 收货地址 → 编辑/新增/设为默认。
- 跨境地址要求：**英文地址、正确邮编、含国家/地区、有效联系电话**（缺失会导致清关失败）。
- 修改已提交订单的地址见上文。

### Q：地址填错了怎么办？

- 未发货：联系客服拦截修改，或取消重拍；
- 已发货：联系承运商改派；
- ⚠️ 因地址错误导致退运或丢失，运费与关税损失由买家承担。

## 四、动作类问题（需系统能力，非知识回答）

| 用户诉求 | 正确处理方式 |
|---|---|
| 我的包裹到哪了？ | 调物流接口返回真实轨迹（含清关状态），无数据答「未更新」 |
| 帮我催一下 | 满足催件条件后创建工单，回复已催件 |
| 修改收货地址 | 走地址修改/拦截流程 |
| 会不会被税？ | 只能说明 DDP/DDU 口径，不得承诺未被税 |
