# 售前咨询与下单支付 FAQ（跨境 · 模拟数据）

【模拟数据 · 内容虚构，仅供演示与评测，不得对客输出】

> 文档编号：DEMO-XB-FAQ-001　版本：v1.0　生效日期：2026-09-20　维护：演示跨境店铺客服部
> 适用场景：跨境订单的售前咨询（有货/发货/配送范围/正品/尺码换算/适用人群/优惠）与下单支付（国际支付方式/汇率/关税/改单）。
> 政策类口径（退货窗口、退款时限、运费承担）以 `docs/customer-service/demo-kb/` 既有政策文档为准，本文件只做简要指引。

## 一、售前咨询

### Q：在吗？有人吗？

亲，您好，在的～请问有什么可以帮您？（跨境订单按当地时间 9:00-22:00 在线，非在线时段留言次日回复）

### Q：有货吗？什么时候发货？

| 商品类型 | 发货时效 |
|---|---|
| 现货商品 | 付款后 **48 小时内** 发出 |
| 预售商品 | 详情页标注为准（常见付尾款后 7 天） |
| 保税仓 / 海外仓商品 | 清关后 48 小时内发出，整体到手 5-15 个工作日 |

### Q：发什么快递？包邮吗？能指定快递吗？

| 项目 | 口径 |
|---|---|
| 默认承运 | 国际专线 / 邮政小包（系统按目的地自动匹配） |
| 包邮门槛 | 单笔实付满 **99 元**（或等值外币）包邮 |
| 偏远/特殊地区 | 部分国家/地区加收运费，下单页会显示实际运费 |
| 指定承运商 | 不支持指定；可联系客服咨询是否支持加急专线（差价自负） |

### Q：能寄到我所在的国家吗？多久能到？

| 区域 | 在途时效（发货后起算） |
|---|---|
| 美国 / 加拿大 | 7-12 个工作日 |
| 英国 / 德国 / 法国等欧洲国家 | 7-15 个工作日 |
| 日本 / 韩国 / 新加坡 | 5-10 个工作日 |
| 其他地区 | 以结算页显示的可配送范围与时效为准 |

- 结算页**不显示派送选项**的地区即为不配送区域，不支持下单。
- 不覆盖地区（如澳大利亚、巴西等）**不配送**，也不得承诺「想办法寄」。

### Q：是正品吗？有授权吗？

- 本店为品牌**官方授权**跨境店铺，全部商品正品保障。
- 可提供品牌授权书；进口商品可提供报关单与合规标签信息（涉密部分打码）。
- 承诺：正品保障，如经品牌方或权威机构鉴定为假货，**全额退款并承担鉴定费用**。

### Q：尺码怎么选？（跨境尺码换算）

- 详情页尺码表提供 **US / UK / EU / JP 对照**，请以**脚长/身体实测数据**为准，不要只看标签码。
- 换算建议：
  - 鞋类：US 码通常比 EU 码偏小 0.5-1 码；脚宽/脚背高建议选大一码。
  - 服装：EU 38 ≈ US 8 ≈ UK 12（女装参考）；亚洲版型普遍比欧美版型小 1 码，建议按实测胸围/腰围选择。
- 尺码不合适可退换（窗口按**收货地政策**：美国 30 天 / 英国·德国 14 天 / 加拿大 21 天 / 日本 7 天），运费按原因判定（无理由 → 买家承担，见 `policy-shipping-fee.md`）。

### Q：材质是什么？会掉色吗？会起球吗？

- 材质成分见商品详情页「Material / 面料成分」栏。
- 深色棉质首次洗涤轻微浮色属正常；毛呢类摩擦部位轻微起球属面料特性。
- 大面积掉色、染色其他衣物、非摩擦部位大面积起球 → 属质量问题，可申请退换（详见 `policy-return-*.md`）。

### Q：适合我吗？孕妇/敏感肌/儿童能用吗？

| 人群 | 口径 |
|---|---|
| 孕妇 | 体脂/称重类商品的**体脂功能（生物电阻抗）不建议孕妇使用**；护肤/贴身类请先查看成分并咨询医生 |
| 敏感肌 | 建议先在耳后/手腕内侧小面积试用；不适请立即停用，并按**收货地退货窗口**申请退货（见 demo-kb 各国政策） |
| 儿童 | 电子类、发热类、刀头类商品**须成人监护**使用 |

### Q：有优惠吗？能便宜点吗？有赠品吗？

- 页面价格为当前活动价，客服**无权改价**。
- 可领取店铺优惠券（Coupon）后下单，结算页显示最终到手价。
- 赠品以商品页标注为准（标注 Gift 的随单发出）；赠品漏发核实后补发。
- 议价统一回复：价格已是活动最低价，可以领券更划算。

### Q：能开发票 / 收据吗？

可以。支持电子发票（Invoice / Receipt）与税务凭证，详见本目录 `policy-invoice-tax.md`。

## 二、下单与支付

### Q：怎么下单？

1. 选择规格（颜色/尺码/数量）→ 加入购物车或立即购买；
2. 填写**国际收货地址**（务必填写英文地址、邮编、联系电话，含国家/地区）；
3. 确认运费与关税说明 → 提交订单；
4. 选择支付方式并完成付款。

### Q：支持哪些支付方式？

| 方式 | 是否支持 | 说明 |
|---|---|---|
| 信用卡 / 借记卡（Visa / Mastercard / JCB） | ✅ | 需支持境外支付 |
| PayPal 等电子钱包 | ✅ | 到账较快，退款约 1-3 个工作日 |
| 本地支付方式（iDEAL / Konbini 等） | ✅ | 视国家/地区开放 |
| 支付宝 / 微信支付 | ✅ | 主要面向中国大陆用户 |
| 货到付款（COD） | ❌ | 跨境订单不支持 COD |
| 银行转账 / 私人转账 | ❌ | 不支持，谨防诈骗 |

### Q：支付失败怎么办？

依次尝试：① 更换支付方式；② 更换网络环境；③ 检查信用卡是否开通境外支付/额度是否充足；④ 退出重进后重新提交。
若已扣款但订单未生成：保留银行/支付平台扣款凭证，联系客服核单，一般 1-3 个工作日原路退回。

### Q：关税 / 税费谁承担？会被扣关吗？

| 情形 | 口径 |
|---|---|
| 商品页标注「关税已含（DDP）」 | 关税由商家承担，用户无需额外支付 |
| 商品页标注「关税自理（DDU）」 | 用户需在清关时自行缴纳目的地关税/增值税 |
| 清关滞留 | 目的地清关超过 **48 小时**未放行，客服可协助催促（见 `policy-logistics-exception.md`） |
| 因用户未缴税导致退运 | **往返运费及产生的关税损失由买家承担** |

> 客服不得承诺「一定不会被税」——是否征税由目的地海关决定。

### Q：能改地址、改规格、改颜色吗？

- **未发货**：不支持直接修改，建议取消后重拍；仅改收货地址可联系客服尝试拦截修改（不保证成功）。
- **已发货**：无法修改订单，可联系承运商改派（可能产生改派费）。
- ⚠️ 跨境地址一旦填错，包裹可能退运或丢失，**退运运费由买家承担**。

### Q：能合并订单吗？能取消订单吗？

- 合并：不支持合并订单。
- 取消：未发货可在订单页自行取消，款项原路退回；已发货需拒收或走退货流程（拒收退运运费买家承担）。

### Q：优惠券为什么用不了？

常见原因：未达门槛、品类不适用、已过期、与其他活动互斥（特价/闪购商品通常不参与用券）、同一订单同类券不可叠加。

## 三、动作类问题（需系统能力，非知识回答）

| 用户诉求 | 正确处理方式 |
|---|---|
| 我的包裹到哪了？ | 调物流接口返回真实轨迹；无数据答「未更新」，禁止编造 |
| 帮我催一下 | 校验订单后创建催件工单（成熟条件见 `policy-logistics-exception.md`） |
| 帮我改地址 | 未发货走拦截流程；已发货转承运商改派 |
| 帮我退款/取消 | 走售后/取消流程，金额与状态以系统为准 |
| 要缴多少关税？ | 属于目的地海关裁定，只能提供估算口径，不得承诺具体金额 |
