# 售后细则

> 版本：v1.0　|　生效日期：2026-11-04　|　适用范围：本商城自营商品订单（演示环境口径，生产上线前所有【业务确认】项须经业务方复核）

## 1. 破损/错发处理

- **签收时发现破损**：当场拍照留证，24 小时内联系客服【业务确认】；核实后支持免费退换或仅退款，运费商家承担；
- **错发/漏发**：提供订单号与实物照片，核实后免费补发或退款，运费商家承担；
- 商家责任（破损、错发、漏发）类售后**不受 7 天无理由时限限制**，按质量问题 15 天内申请【业务确认】。

## 2. 仅退款 vs 退货退款

| 场景 | 适用方式 |
|---|---|
| 低值商品质量问题（协商一致）【业务确认】 | 仅退款，无需退货 |
| 商品未发出 | 取消订单或仅退款 |
| 已发货质量问题 | 退货退款（商家承担运费）或协商仅退款 |
| 7 天无理由 | 退货退款（买家承担回程运费） |
| 破损/错发要求换货 | 换货（商家承担往返运费） |

- 仅退款金额 = 商品实付金额（券后价口径），运费另按承担规则计算【业务确认】。

## 3. 换货与维修

- 换货：同款有货时优先换货，无货转退款；换货发出后 3-5 个工作日送达【业务确认】；
- 维修：质保期内非人为故障走换新/维修（见《常见问题》保修条目），质保期外提供付费维修报价【业务确认】。

## 4. 时效汇总

| 环节 | 时效【业务确认】 |
|---|---|
| 售后申请人工审核 | 24 小时内 |
| 退货签收后验收 | 2 个工作日 |
| 验收合格后退款 | 实时退回账户余额 |
| 换货补发 | 验收合格后 48 小时内发出【业务确认】 |

## 5. 证据要求

- 破损/质量问题：订单号 + 商品照片（含运单号与商品整体/细节）；
- 错发/漏发：订单号 + 实物与清单对照照片；
- 材料齐全可显著加快审核，缺失时客服会引导补交。

## 6. 例外与升级路径（转人工）

- 售后类型判定争议（仅退款/退货退款/换货间选择）；
- 商家责任认定争议；
- 多次售后未闭环、涉及金额较大（≥ 500 元【业务确认】）的纠纷。

回复「转人工」进入人工队列，服务时间 9:00-21:00（节假日不休）。
