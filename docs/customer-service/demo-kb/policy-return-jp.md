# 退货退款政策 — 日本订单（模拟数据）

> 适用范围：收货地址在日本的演示订单。政策版本：DEMO-POLICY-JP-2026.09（模拟）

## 退货条件

1. 平台标准退货窗口：签收后 **7 天内**（模拟口径，短于欧美）。
2. 商品需未使用、原包装完整，附全部附件与说明书。
3. 食品类、贴身类商品一经签收非质量问题不退。

## 退款方式与时限

- 验收合格后 **5 个工作日**内原路退款。
- 退款金额为商品实付金额，标准运费视退货原因确定（见运费规则）。

## 质量问题退货

- 质量缺陷商品不受 7 天限制，签收后 **30 天内**可申请，运费由商家承担。
- 需提供问题照片，必要时配合商家指定的检测流程。
