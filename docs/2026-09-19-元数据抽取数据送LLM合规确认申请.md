## 1. 申请事项

## 2. 数据流向（事实陈述）

```
用户上传文档（企业知识库）
  → 文本采样（头 60% / 中 20% / 尾 20%，上限 6000 字符，METADATA_LLM_EXTRACT_MAX_CHARS）
  → prompt 拼装（含文件名）
  → HTTPS 出网至第三方云 LLM API（qwen3.7-plus@tp，备选 qwen3.7-plus / DeepSeek API）
  → 返回 JSON（doc_type/摘要/关键词/实体/时间引用/风险标记）
  → 落库（agent_business 元数据表 + trace）
```

- 发送内容：**文档正文采样（≤6000 字）+ 文件名**。非全量文档；非聊天记录；非用户身份信息。
- 触发频率：每次文档上传 1 次（统一抽取主路径）；级联路由 L0-L2 命中时 0 次。
- 供应商：现有 `backend/infra/llm` proxy 同一出口（与聊天/摘要链路同源，无新增供应商）。

## 3. 数据类别与敏感性

| 类别 | 是否涉及 | 说明 |
|---|---|---|
| 个人信息（姓名/身份证/银行卡） | 可能 | 实体抽取字段会提取 person 名；正文采样可能含个人信息 |
| 财务数据 | 可能 | 财务类文档（发票/报销台账） |
| 商业秘密（合同/报价） | 可能 | legal/financial 类文档全文采样 |
| 特殊类别个人信息 | 预期不涉及 | 知识库为电商运营文档；如发现需标注 |

## 4. 现有防护（代码事实，非承诺）

- **财务文档强制 PII 脱敏**：`FINANCIAL_PII_MASK_FORCE=true`（银行卡/身份证/统一社会信用代码/纳税人识别号四类正则，`FINANCIAL_PII_PATTERNS`）。
- **全局 PII 脱敏默认关闭**：`FILTER_ENABLE_PII_MASK=false`——即非财务文档**未脱敏即出网**（现状）。
- **预算与审计**：LLM_BUDGET_MODE=enforce；proxy 层全量计量落库（llm_usage_store）；prompt 内容不进访问日志。
- **不在 prompt 中发送**：用户身份头、租户标识、会话历史。
