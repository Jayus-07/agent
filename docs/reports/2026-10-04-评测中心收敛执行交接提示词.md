## 4. 铁律（违反=返工）

- **提交双路径限定**：`git add -A -- <paths>` + `git commit -m "..." -- <paths>`；提交前查 diff 新增符号的定义文件是否同批提交（引用闭环）；Conventional Commits 中文
- **混线甄别**：开工前 `git status`；发现要改的文件已有他人未提交改动 → 查 `git diff` 判归属，混线文件不整文件提交（`git commit -- path` 按**工作区**内容提交，hunk 手术必须保持到 commit 完成——上一会话在 test_prompt_alias.py 上收编过一行，已披露，勿重蹈）
- **跑全量 pytest 前先确认无并行会话在跑**（约 20 分钟冻结期，期间不改 backend 不动容器）；本项目验收用定向测试，不跑全量
- **动容器前只读核查**：`docker ps` / `docker port` / `docker inspect`；会停掉别人容器的操作先报告
- **不新增未经施工书授权的范围**；每张卡做完立即验证+提交，不留大批未提交工作区
- 迁移只走 `backend/sql/migrations/`，**必须同时登记 `scripts/init_db.py`**（未登记文件会让 init_db fail-fast）
