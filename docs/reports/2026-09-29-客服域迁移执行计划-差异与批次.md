## 三、迁移纪律（继承方案 §14.3，逐条落到执行）

1. 契约冻结：确认链 / dispatch / identity-header 三契约逐字冻结；B 系列任何 diff 触碰即停下走版本化评审。
2. 每批次一个主题：小步提交（pathspec 双限定）、先测试后提交、报告落 `docs/reports/`。
3. 行为变更必须带开关或双跑对比；等价重构必须以全量回归门证明等价。
4. 并行会话纪律：开工前 `git status` 核对；触碰别人的未提交文件立即停手。
