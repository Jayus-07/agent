## 1. 结论速览

- **子 Agent 层**：方案裁决「不增设 Agent」，七职责中六个已有落点；**唯一结构性缺失 = Travel Assistant**（`core/agent_base.py:80-85` 有 AgentSpec、`core/actions.py:31` QUERY 枚举已预留但明写「接线在 Phase 6」，无任何节点消费）。当前「为什么这样排／哪天最贵」会经 travel_prefilter → travel_graph_node **全链重跑**，没有任何只读直答通路。
- **Tool 层**：真身已有、只缺 Tool 面的有 4 个（poi.detail / weather.query / retrieve_knowledge / map.link）；需完全新写的 3 个（opening_hours 指定日期查询、hotel.region_suggest、food.search）；plan 版本四件套中仅 plan.diff 有纯函数实现（生产零调用），preview/commit/restore 全缺。
- **Provider 层（BLOCKED，勿假装可用）**：ticket.facts（腾讯无票价/营业时间字段，`live/capabilities.py:32-35` 冻结）、城际真实车次、活动源、官方公告源、hotel/flight/booking live 凭据（fake:commerce 显式披露）、餐饮菜单/人均/评分。
