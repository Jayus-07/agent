## 1. 问题（收口前）

主图 runner（`orchestration/graph/runner.py`）worker 与生成器两级 `except Exception` 把所有异常一锅端成手写「执行失败: …」帧，四类语义被压平：

| 语义 | 收口前行为 |
| --- | --- |
| 用户主动取消（stop_event → 取消边界抛 `RequestCancelled`） | 逃逸边界落入 `except Exception`：发出「执行失败: request cancelled at <stage>」帧——伪装系统故障 + 内部 stage 名泄漏进用户帧 + 与主循环 aborted 分支的「用户中止」帧**重复发两条 error 终帧**（违反终帧互斥契约）；trace 终态在部分路径被误标 error |
| 请求 deadline 超时（`TimeoutError`/`asyncio.TimeoutError` 冒泡） | 与普通异常同帧「执行失败」，无稳定码；trace 无归因 |
| Provider 超时（`httpx.TimeoutException`） | `error_protocol._exception_code` 不识别（httpx 超时异常不是内置 `TimeoutError` 子类）→ 判 INTERNAL_ERROR；全局兜底 handler 一律 HTTP 500 |
| 工具失败 | 已由 `tool_runtime/error_mapper` 归一为 ToolStatus + degraded 步骤结果（复用，未改动） |

另有两处附带缺陷：生成器级 catch 把堆栈尾 12 行拼进 SSE message（STOP H 只收口了 worker 路径）；`ContextBudgetExceededError` 终帧缺契约必填 `ts`。

## 2. 改动（最小范围）

| 文件 | 改动 |
| --- | --- |
| `backend/shared/error_protocol.py` | ① 新增第 10 码 `REQUEST_CANCELLED`（safe message「请求已由用户中止。」，retryable=False）；② `_exception_code` 识别 `RequestCancelled` 与 `httpx.TimeoutException`；③ `sse_error_event` 支持 `message` 安全覆盖并补 `ts`（ErrorData 契约必填）；④ 新增 `sse_cancelled_event()` 统一中止终帧构造器 |
| `backend/orchestration/graph/runner.py` | worker：`RequestCancelled` 单独捕获 → `aborted=True`（不发「执行失败」帧，终帧由 aborted 分支统一发）；`TimeoutError` 单独捕获 → TIMEOUT 协议帧；generic 异常改走协议封套（保留「执行失败: 单行原因」文案）。生成器级 catch 同样三分支收口，堆栈尾不再进用户 message。`_finalize_trace` 新增 `error_code` 参数 → `trace.tags/metadata["error_code"]`。预算终帧补 `ts` |
| `backend/orchestration/graph/events.py` | `emit_delta_events` 中止帧改用 `sse_cancelled_event()` |
| `backend/app/exceptions.py` | 全局兜底 handler 按封套 code 映射 HTTP 状态：TIMEOUT→504、UPSTREAM_UNAVAILABLE→503、RATE_LIMITED/BUDGET_EXCEEDED→429、REQUEST_CANCELLED→499（nginx 客户端取消惯例）等；未列码保持 500 |
| `backend/core/request_context.py` | `RequestCancelled` docstring 明确：**逻辑取消 ≠ 底层线程/Provider 已停止**——取消检查边界保证不再启动新调用，已入场的同步调用自然跑完、结果被丢弃；物理取消传播属后续批次 |
| `docs/contracts/error-protocol.schema.json` | code enum 增加 `REQUEST_CANCELLED` |
| 测试 | `test_error_protocol.py`：冻结码集更新 + 5 个新用例；新增 `test_runner_terminal_semantics.py`：五路定向（正常/取消/超时/异常/终帧唯一性）+ 全流过 `event_schema` 契约门 |

## 3. 语义矩阵（收口后）

| 语义 | SSE error 帧 | trace 终态 | HTTP（全局兜底路径） |
| --- | --- | --- | --- |
| 用户主动取消 | `code=REQUEST_CANCELLED`，retryable=false，恰好一条 | `cancelled` + cancel_source/cancel_stage | 499 |
| 请求 deadline / Provider 超时冒泡 | `code=TIMEOUT`，retryable=true | `error` + `metadata.error_code=TIMEOUT` | 504 |
| 上游不可用 | `code=UPSTREAM_UNAVAILABLE` | error | 503 |
| 普通异常 | `code=INTERNAL_ERROR`，单行原因，无堆栈 | error | 500 |
| 工具失败 | 不产生终态错误（degraded 步骤结果，走 done） | business_outcome=degraded/failed | — |
