## 二、M8 关键设计决策（偏差记录）

1. **落库方式：设计「POST 落库」→ 实施直连 PG 5433**。原因：① e2e_domain 是
   editor 无 admin 权限，POST 需管理员凭据进发布环境（新增凭据负担）；
   ② `--skip-build` 场景旧容器无新端点（鸡生蛋）；③ 与 gate 脚本既有
   docker exec psql（g3/g10）脚本侧 DB 访问先例一致。落库失败=发布无记录=违规，
   exit 1 fail-loud；`--no-record` 供本地调试。
2. **迁移编号连续让位**：本批先建 061 → 并行会话（tool_contract_changes）占用
   061/062 → 本表最终落 **063**。两边登记同文件 `scripts/init_db.py`，对方提交
   a5515c6 将两侧登记一并带走的收编事实已在台账记录。
3. **表结构**：git_sha/build_time/gates JSONB/gate_details JSONB/result
   (PASS|FAIL)/operator/started_at/finished_at。回滚判据=最近一条 PASS 的
   git_sha（/releases 页直接展示重建命令）。
4. **CI 范围裁决**：三个 `.disabled` 是 6da8888 有意整体暂停（「CI 待重新设计」）。
   本批只接 lock 漂移检测链（release.sh 执行点① + tool_quality 执行点②，后者由
   并行会话完成）；unit-tests/rag_eval 维持 disabled——CI runner 无 PG/Redis
   容器依赖必红，启用属「CI 重新设计」范畴，不盲目放开。
