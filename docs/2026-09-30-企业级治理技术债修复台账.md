## D1（M1）Tool 契约快照 lock + 变更分类

**为什么/解决什么**：34 个 Tool 的契约（args_schema、output_type、封套）无快照无 hash，7 组守卫测试 CI 全 disabled，破坏性变更只能靠人记得跑测试；事后无法回答「哪个构建改了什么契约」。

**修改模块**：新增 `backend/scripts/gen_tool_contract_lock.py`（生成/比对/分类）+ `backend/tool_contracts.lock.json`（派生快照，进版本库）+ `backend/tests/test_tool_contract_lock.py`；后续接 release.sh 与 CI（属 D1 第二步，随 M8 一起接）。

**契约条款（每 Tool）**：`name / module(相对路径) / args_schema(canonical JSON: 参数名→类型，必填与否) / output_type(skill 声明侧，可空) / envelope(若该 tool 被 map/_base 封套约束) / capabilities(引用它的 capability 列表) / content_hash(sha256[:16])`；顶层 `generated_at / git_sha / lock_hash / tool_count`。

**变更分类规则（diff 自动判定）**：
- BREAKING：删除 Tool、删除参数、参数类型变更、可选→必填
- DEGRADED：新增必填参数、output_type 变化、structured↔text 翻转
- COMPATIBLE：新增可选参数、描述变化、新增 Tool、capability 归属变化

**不影响已有功能**：纯派生脚本+快照文件，零运行时依赖；registry 不变。

**验收门**：① 生成 lock 与 tool_registry 实时派生一致（count=34）；② 单测覆盖三种分类各至少 1 例；③ `--check` 在 lock 被人为篡改时 exit 1 且输出分类；④ 一致性三件套回归绿。

## D2（M2）Tool 调用统计聚合端点

**为什么/解决什么**：`agent_tool_*` 指标齐全但管理端无聚合视图；`skill_failure_total` 死指标。管理员答不了「哪个 Tool 在失败、为什么」。

**修改模块**：新增 `backend/app/api/routes/admin_tools.py`（GET /api/admin/tools、/api/admin/tools/stats）+ 测试。stats 数据源优先复用 `/skill-health` 的 span 聚合模式 + tasks.error_type SQL 聚合；死指标 `skill_failure_total` 补埋点（skill base 失败路径一处）。

**验收门**：端点 200、字段齐（总数/成功/失败/成功率/Top失败Tool/Top错误码）、错误码来自 D3 统一分类；有测试（mock span store）。

## D3（M3）错误七分类统一口径

**为什么/解决什么**：三套正交词表（模型层 5 类 `infra/llm/error_taxonomy.py`、任务层 10 类 `tasks/error_taxonomy.py`、Tool 层 ToolStatus 8 值 `core/tool_runtime/models.py`）各自为政，聚合不出统一失败分布。

**修改模块**：新增 `backend/observability/error_taxonomy.py`（`unify_error_class()` 纯映射，零 IO）+ `backend/tests/test_error_taxonomy_unify.py`；接入点① `agent_tool_calls_total` 加 `error_class` 标签（tool_runtime metrics 埋点）；接入点② trace_summary.error_class 列（writer 侧，随 migration 批次）。

**映射表**（实施依据，报告 §4.6）：timeout←{模型timeout｜任务timeout/provider_timeout｜ToolStatus timeout}；network_error←ToolStatus unavailable；permission_denied←{模型auth_failed｜任务permission_denied/auth_failed｜ToolStatus unauthorized}；validation_error←{任务validation_error/illegal_transition｜ToolStatus invalid_request}；business_error←{任务internal_error｜ToolStatus failed}；contract_error←ToolStatus degraded；provider_error←{模型provider_error/rate_limited/quota_exhausted｜任务rate_limited/quota_exhausted/provider_error｜ToolStatus rate_limited}。

**验收门**：三套词表枚举值 100% 覆盖映射（穷举单测）；未知值落 `unknown` 且 warning；metrics 出现新标签。

## D6（M6）资产一致性报告端点
