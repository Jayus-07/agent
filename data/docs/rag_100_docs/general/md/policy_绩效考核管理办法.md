# 绩效考核管理办法

制度编号：XC-HR-2025-029
发布部门：人力资源部
生效日期：2025-10-01

## 1. 考核周期
全员**半年度**考核，分别在 1 月与 7 月开展。

## 2. 等级分布
考核结果分为 **A / B / C / D** 四档，实行强制分布：
A 档**不超过 20%**，D 档**不低于 5%**。

## 3. 结果应用
**连续两次考核为 D** 的员工进入绩效改进计划（PIP），改进期 **3 个月**；
改进期满仍未达标的，按人岗不匹配处理。

## 4. 申诉
对结果有异议的，可在结果告知后 10 个工作日内向 HRBP 提出书面申诉。
