## 二、文档使用约定

1. **模板头**：每篇正式文档均包含「公司名 / 版本 / 生效日期 / 文档编号 / 维护部门」五项元信息，便于版本追溯。
2. **虚构声明**：每篇文档均带 `【仅供测试 · 内容虚构】` 标识，不得对外引用。
3. **版本更新**：内容变更须同时更新版本号与生效日期，旧版本归档至 `archive/`。
4. **权限**：本目录整体属于公司内部资料；按 doc# 前缀做访问控制：
   - `FAQ-*`/`CS-*`/`RETURNS-*` 可对外公示
   - 其他文档仅限内部按角色访问

## 三、写作规范反例

`写作规范反例/` 子目录收录刻意编写的"反例文档"，用于内部文档写作培训，**不属于正式企业文档库**，不要在业务中引用。
