# 写作规范反例（培训素材 · 非正式文档）

> **本目录文档为刻意编写的反例，仅用于内部文档写作培训，不得在业务中引用。**
> 版本：v1.0　生效日期：2026-08-26

## 反例清单

| 文件 | 反例类型 | 错误要点 | 写作课建议议题 |
|------|----------|----------|---------------|
| `10_结构混乱的长文档.pdf` | 结构混乱 | 无章节、无标点、列表混用、TAB/超长无段落标题、Lorem ipsum 干扰 | "如何搭建文档骨架" |
| `16_一句话FAQ.md`            | 信息过薄 | 整篇仅一句话，无法回答任何问题 | "FAQ 的最小信息密度" |
| `24_关键词干扰文档.md`        | 标题党/堆砌 | 标题写满关键词，正文空洞 | "题文一致性" |
| `25_同形异义词.md`            | 用词歧义 | 同一词指代不同事物未做区分 | "术语表与首次定义" |
| `26_数字近似陷阱.md`          | 数据不精确 | 关键数字模糊（"大约"/"左右"/"差不多"） | "量化表达与数据精度" |

## 使用方式

- 新员工入职文档培训：以本目录 5 篇反例为案例，引导讨论"问题在哪、应如何改正"。
- 文档评审参考：评审他人文档时，对照本目录检查是否落入常见反例。
- 内部考试素材：可作为"识别问题文档"的考核题。

## 维护

本目录由文档管理委员会维护，每年评估一次是否新增/替换反例。
